# 뉴질랜드 와인 개요

![뉴질랜드 주요 와인 산지 지도](../assets/newzealand-overview.svg)

> **남위 34~46°.** 세계에서 가장 남쪽에 있는 상업 와인 산지다. 국토가 좁고 길어 **어디서나 바다가 130 km 이내**이며, 이 극단적 해양성이 뉴질랜드 와인의 산도와 향을 만든다.

## 1. 세계 와인 지도를 바꾼 40년

| 시기 | 사건 |
|---|---|
| 1819 | 첫 포도 식재(선교사 새뮤얼 마스든) |
| 1970년대까지 | **뮐러투르가우와 하이브리드 중심**의 소규모 산업. 주류법 규제도 강했다 |
| **1973** | **Montana 몬태나**(현 Brancott)가 말버러에 처음 포도를 심었다 — 당시 아무도 그곳을 와인 산지로 보지 않았다 |
| **1985** | **Cloudy Bay 클라우디 베이** 첫 빈티지. 런던에서 폭발적 반응 |
| 1990~2000년대 | **말버러 소비뇽 블랑**이 세계 시장을 장악. "뉴질랜드 = 소비뇽"이 굳어졌다 |
| **2000년대~** | 센트럴 오타고 피노 누아, 호크스 베이 보르도 블렌드, 샤르도네·리슬링 재평가 |
| 2010년대~ | **스크루캡 100%에 가까운 전환**, 지속가능 인증(SWNZ) 약 96% |

> **뉴질랜드 소비뇽 블랑의 정체** — 말버러의 강한 자외선과 큰 일교차가 **메톡시피라진(풀·피망)**과 **티올(패션프루트·자몽)**을 동시에 극단적으로 끌어올린다. 루아르 상세르가 광물성·회양목 쪽이라면, 말버러는 **열대과일과 풀이 동시에 폭발**한다. 좋아하든 싫어하든 **한 번에 알아볼 수 있는 스타일**을 만든 것이 이 나라의 성취다.

## 2. 산지 제도

| 항목 | 내용 |
|---|---|
| 제도 | **GI(Geographical Indications) — 2017년 법제화.** 경계만 정한다 |
| 라벨 규정 | **품종·산지·빈티지 모두 85% 이상** |
| 특징 | **등급 서열이 없다.** 호주 GI·미국 AVA와 같은 구조 |
| 인증 | **Sustainable Winegrowing New Zealand (SWNZ)** — 포도밭의 약 96%가 인증. 세계 최고 수준 |

## 3. 품종

| 품종 | 재배 비중 | 성격 |
|---|---|---|
| **Sauvignon Blanc 소비뇽 블랑** | **약 63%** | 패션프루트·자몽·풀·피망. 산도 매우 높다 |
| **Pinot Noir 피노 누아** | 약 13% | 센트럴 오타고·마틴버러·말버러 |
| **Chardonnay 샤르도네** | 약 5% | 기스본·호크스 베이. 최근 급상승 |
| **Pinot Gris 피노 그리** | 약 5% | 몸통 있는 오프드라이 |
| **Merlot 메를로 · Cabernet Sauvignon · Cabernet Franc · Malbec** | 약 5% | **호크스 베이** 김밋 그래블스 |
| **Riesling 리슬링** | 약 2% | 와이파라·센트럴 오타고. 드라이~오프드라이 |
| **Syrah 시라** | 약 1% | **호크스 베이** — 북부 론 스타일, 급부상 |
| **Albariño · Grüner Veltliner · Chenin Blanc** | 소량 | 실험 |

> **소비뇽 블랑 63%의 함정** — 한 품종이 재배의 3분의 2, 수출의 **약 85%**를 차지한다. 산업 전체가 한 품종·한 산지(말버러)에 걸려 있다는 구조적 취약성이 자주 지적된다.
