# 남섬 South Island — 말버러 · 센트럴 오타고 · 와이파라 · 넬슨

![뉴질랜드 주요 와인 산지 지도](../assets/newzealand-overview.svg)

| 산지 | 재배 비중 | 주력 | 한 줄 |
|---|---|---|---|
| **Marlborough 말버러** | **약 70%** | 소비뇽 블랑 | 뉴질랜드 산업 그 자체 |
| **Central Otago 센트럴 오타고** | 약 5% | **피노 누아** | 세계 최남단 산지, 유일한 대륙성 |

| **Nelson 넬슨** | 약 2% | 소비뇽 · 피노 · 아로마틱 | 말버러 서쪽, 더 습윤 |

# 1. 말버러 Marlborough

> 1973년까지 **양 목장**이었다. 지금은 뉴질랜드 포도밭의 70%, 수출의 85%가 여기서 나온다.

| 항목 | 내용 |
|---|---|
| 위치 | 남섬 북동단. **남알프스가 서풍의 비를 막는다** |
| 일조 | **뉴질랜드에서 가장 맑다.** 연 2,400시간 이상 |
| 일교차 | 여름 낮 25℃ / 밤 10℃ — **큰 일교차가 산도와 향을 지킨다** |
| 자외선 | 오존층이 얇아 **자외선이 강하다** → 껍질의 향 전구체가 크게 발달 |
| 강우 | 연 650 mm, 수확기는 건조 |

## 두 개의 밸리

| 밸리 | 토양 | 성격 |
|---|---|---|
| **Wairau Valley 와이라우 밸리** | **자갈질 충적토**(과거 강바닥), 배수 강함 | **패션프루트·구아바 등 열대과일** 쪽. 풍만하고 향이 화려 |
| **Awatere Valley 아와테레 밸리** | 석회질·점토, 더 척박 | **더 서늘하고 바람이 강하다.** 토마토잎·허브·짠맛. 산도가 더 높다 |
| **Southern Valleys 서던 밸리스** | 점토 비율 높음 | **피노 누아**에 유리 |

> **말버러 소비뇽의 화학** — 강한 자외선과 큰 일교차가 두 계열 향을 동시에 극대화한다. **메톡시피라진**(풀·피망·아스파라거스, 덜 익을수록 증가)과 **티올**(패션프루트·자몽·회양목, 익을수록 증가)이 보통은 반비례하는데, 말버러에서는 **둘 다 높게 나온다.** 이것이 이 스타일이 유일무이한 이유다.

## 스타일의 분화

| 유형 | 내용 | 생산자 |
|---|---|---|
| **클래식** | 스테인리스, 저온 발효, 조기 병입. 향 폭발 | Cloudy Bay, Villa Maria, Brancott |
| **오크·앙금 숙성형** | 통 발효, 앙금 숙성. 질감과 숙성력 | **Cloudy Bay "Te Koko"**, Dog Point Section 94, Greywacke Wild Sauvignon |
| **단일 밭·자연 효모** | 밭 표현 지향 | **Dog Point 도그 포인트**, **Greywacke 그레이와키**, Astrolabe |

**핵심 생산자**: **Cloudy Bay 클라우디 베이**(LVMH) · **Dog Point 도그 포인트** · **Greywacke 그레이와키**(케빈 저드 — 클라우디 베이 초대 양조가) · **Fromm 프롬** · **Seresin 세레신** · **Te Whare Ra** · Villa Maria · Auntsfield

> **말버러 피노 누아**도 상당량 만들어진다. 센트럴 오타고보다 가볍고 붉은 과실 쪽이며, **Southern Valleys 서던 밸리스**의 점토 구획이 최상급이다.

# 2. 센트럴 오타고 Central Otago

> **남위 45°, 세계 최남단 상업 산지.** 뉴질랜드에서 **유일하게 해양성이 아닌 대륙성** 기후다.

| 항목 | 내용 |
|---|---|
| 위치 | 남섬 내륙 산악. 해발 200~450 m |
| 기후 | **대륙성** — 여름 35℃, 겨울 -5℃. 일교차 극단적 |
| 강우 | 연 350~400 mm. **뉴질랜드에서 가장 건조** |
| 위험 | **봄·가을 서리.** 헬리콥터와 송풍기로 방어한다 |
| 품종 | **Pinot Noir 피노 누아 약 75%** · Pinot Gris · Riesling · Chardonnay |
| 토양 | **편암(schist)** + 뢰스 + 빙하 자갈 |

## 6개 하위 구역

| 구역 | 성격 |
|---|---|
| **Bannockburn 배녹번** | 가장 덥고 건조. **응축도 최고**, 향신료·검은 과실 |
| **Cromwell / Lowburn / Pisa 크롬웰·로번·피사** | 호수 옆, 온난. 풍만 |
| **Bendigo 벤디고** | 북향 사면, 가장 덥다 |
| **Gibbston 깁스턴** | **가장 서늘하고 높다.** 늦게 익고 가장 우아 |
| **Alexandra 알렉산드라** | 최남단·최한랭. 일교차 최대 |
| **Wanaka 와나카** | 최북단, 호수 |

> **왜 여기서 피노가 되는가** — 대륙성 기후의 **극단적 일교차**가 향과 산도를 동시에 지킨다. 다만 부르고뉴보다 **자외선이 강하고 건조**해 색과 탄닌이 더 진하다. 부르고뉴보다 **과실이 앞서고 구조가 굵은** 스타일이 나오는 이유다.

**핵심 생산자**: **Felton Road 펠턴 로드**(Block 3 · Block 5 · Calvert — 비오디나미, 이 지역의 기준점) · **Rippon 리폰**(와나카, 비오디나미) · **Burn Cottage** · **Mount Difficulty** · **Two Paddocks**(배우 샘 닐) · Quartz Reef(스파클링) · Valli · Prophet's Rock

# 3. 노스 캔터베리 · 와이파라 North Canterbury · Waipara

| 항목 | 내용 |
|---|---|
| 위치 | 크라이스트처치 북쪽. **Teviotdale Hills 테비오트데일 힐스**가 동풍을 막는다 |
| 토양 | **석회질**(뉴질랜드에서 드물다) + 점토·자갈 |
| 품종 | **Pinot Noir · Riesling** · Chardonnay · Sauvignon Blanc |
| 성격 | 말버러보다 서늘하고 광물적. **리슬링은 뉴질랜드 최고 수준** |

**핵심 생산자**: **Pyramid Valley 피라미드 밸리**(비오디나미, 석회질 단일 밭) · **Bell Hill 벨 힐**(극소량, 석회질) · **Pegasus Bay 페가수스 베이** · **Greystone · Black Estate** · Mountford

> **Bell Hill 벨 힐**은 석회 채석장 자리에 심은 극소 면적 피노 누아·샤르도네로, **뉴질랜드에서 가장 구하기 어려운 와인** 중 하나다.

# 4. 넬슨 Nelson

| 항목 | 내용 |
|---|---|
| 위치 | 말버러 서쪽, 산 하나 너머 |
| 기후 | 말버러보다 **강우가 많고 습하다.** 일조는 비슷하게 많다 |
| 구분 | **Moutere Hills 모우테레 힐스**(점토, 몸통) / **Waimea Plains 와이메아 플레인스**(자갈, 아로마틱) |
| 품종 | Sauvignon Blanc · Pinot Noir · **Chardonnay · Riesling · Gewürztraminer** |

**핵심 생산자**: **Neudorf 노이도르프**(Moutere Chardonnay — 뉴질랜드 최고 샤르도네로 꼽힌다) · **Greenhough** · Seifried · Te Mania

# 5. 품종 — 남섬에서의 성격

| 품종 | 어디서 | 성격 |
|---|---|---|
| **Sauvignon Blanc 소비뇽 블랑** | **말버러** | 와이라우는 열대과일, 아와테레는 허브·짠맛. 산도 매우 높다 |
| | 넬슨 · 와이파라 | 조금 더 절제, 광물적 |
| **Pinot Noir 피노 누아** | **센트럴 오타고** | **편암·대륙성.** 색이 진하고 향신료·검은 과실. 구조가 굵다 |
| | 말버러 서던 밸리스 | 더 가볍고 붉은 과실 |
| | **와이파라 (석회질)** | 가장 부르고뉴에 가깝다 |
| **Riesling 리슬링** | **와이파라 · 센트럴 오타고** | 라임·꽃, 드라이~오프드라이. 산도가 매우 높다 |
| **Chardonnay 샤르도네** | **넬슨 (Moutere) · 와이파라** | 절제된 오크, 미네랄 |
| **Pinot Gris 피노 그리** | 전역 | 몸통 있는 오프드라이. 뉴질랜드에서 인기 |
| **Gewürztraminer 게뷔르츠트라미너** | 넬슨 · 기스본 | 소량이나 수준이 높다 |
