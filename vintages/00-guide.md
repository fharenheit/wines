# 빈티지 차트 — 읽는 법

## 1. 이 차트를 어떻게 쓸 것인가

| 원칙 | 내용 |
|---|---|
| **생산자 편차 > 빈티지 편차** | 나쁜 해의 좋은 생산자가 좋은 해의 평범한 생산자보다 낫다. 빈티지는 **1차 필터**일 뿐이다 |
| **평가는 합의이지 사실이 아니다** | Wine Spectator · Robert Parker · Decanter · Jancis Robinson의 평가가 서로 다르다. 이 차트는 그 합의 범위를 정리한 것 |
| **평가는 시간이 지나면 바뀐다** | 1996 보르도는 초기에 과소평가되었고, 1997 바롤로는 초기에 과대평가되었다. **20년이 지나야 결론이 난다** |
| **"약한 해"의 쓸모** | 탄닌이 적고 일찍 열려 **지금 마시기 좋다.** 최상급 생산자의 약한 해는 가격 대비 가치가 가장 높다 |
| **최근 3~4년은 잠정** | 병 숙성 전 평가는 자주 뒤집힌다. 이 차트에서 **2023년 이후는 예비 평가**다 |

## 2. 별점 기준

**채워진 별(★)이 점수이고, ☆는 반 별**이다. 5점 만점.

| 표기 | 점수 | 의미 |
|---|---|---|
| **★★★★★** | 5.0 | **전설적 / 세기의 해.** 최상급은 수십 년 발전 |
| ★★★★☆ | 4.5 | 매우 우수 |
| ★★★★ | 4.0 | 우수. 대부분의 생산자가 좋은 와인을 만든다 |
| ★★★☆ | 3.5 | 좋음 |
| ★★★ | 3.0 | 클래식 · 평균. 생산자를 봐야 한다 |
| ★★☆ | 2.5 | 평범 |
| ★★ | 2.0 | 약함. 상위 생산자만, 일찍 마신다 |
| ★☆ | 1.5 | 어렵다 |
| ★ | 1.0 | 피하거나 아주 싸게 |

## 3. 성숙 표시

| 기호 | 의미 |
|---|---|
| **🔒** | 아직 닫혀 있다. 더 기다릴 것 |
| **▲** | 지금 정점 또는 정점에 가깝다 |
| **◆** | 정점을 지났으나 여전히 좋다 |
| **▼** | 대부분 하락. 최상급만 남았다 |
