# 이탈리아 빈티지 차트 (1955~2025)

> 별점 기준과 성숙 기호는 **[읽는 법](00-guide.md)** 참조. 🔒 더 기다릴 것 · ▲ 지금 정점 · ◆ 정점 지났으나 좋음 · ▼ 최상급만 남음

> **이탈리아 빈티지의 특수 사정** — 바롤로는 **최소 38개월**(리제르바 62개월), 브루넬로는 **5년**(리제르바 6년) 숙성 후 출시된다. 그래서 **시장에 나온 빈티지가 프랑스보다 3~5년 늦다.** 2025년 기준 최신 출시 바롤로는 2021, 브루넬로는 2020이다.

# 6. 이탈리아 빈티지를 읽는 요령

| 요령 | 내용 |
|---|---|
| **출시 시차를 계산할 것** | 바롤로 리제르바는 수확 6년 뒤에 나온다. "2019 바롤로"를 2026년에 사는 것이 정상이다 |
| **북부와 중부는 다르게 움직인다** | 2014는 피에몬테·토스카나 모두 나빴지만, 2011은 피에몬테가 덥고 토스카나는 더 심했다 |
| **약한 해에는 하위 등급을 볼 것** | 2014 브루넬로 대신 **Rosso di Montalcino**, 2002 바롤로 대신 **Langhe Nebbiolo** |
| **고도가 완충 장치다** | 폭염 해(2003·2017·2022)에는 **알토 피에몬테·에트나 고지대·발텔리나**가 유리하다 |
| **1997의 교훈** | 당시 "세기의 빈티지"로 불렸으나 산도 부족으로 20년 뒤 평가가 내려갔다. **즉시 평가를 믿지 말 것** |
