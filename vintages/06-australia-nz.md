# 호주 · 뉴질랜드 빈티지 차트 (1971~2025)

> 별점 기준과 성숙 기호는 **[읽는 법](00-guide.md)** 참조.

> **남반구는 수확이 2~4월이다.** 라벨의 `2020`은 **2019년 가을에 개화해 2020년 3월에 수확**한 포도를 뜻한다. 북반구와 비교할 때 **실질적으로 반년이 앞선다**고 보면 된다.

> **호주·뉴질랜드는 빈티지 편차가 유럽보다 작다.** 여름 강우가 적어 곰팡이 위험이 낮기 때문이다. 대신 **산불(호주)·서리(뉴질랜드 오타고)·사이클론(호크스 베이)**이라는 다른 변수가 있다.

# 4. 읽는 요령

| 요령 | 내용 |
|---|---|
| **남반구 수확 시점** | 2~4월. 라벨 연도의 **전년 가을에 개화**했다 |
| **호주는 산불을 본다** | **2020**(남동부 대화재)이 최대. 2003·2009·2019도 국지적 피해 |
| **뉴질랜드는 사이클론과 서리를 본다** | 호크스 베이는 **2017·2023 사이클론**, 센트럴 오타고는 **봄 서리** |
| **지역마다 좋은 해가 다르다** | 헌터(1~2월 수확)와 남호주(3~4월)는 기상 조건이 겹치지 않는다 |
| **서늘한 해가 재평가된다** | 2017·2021·2022 호주는 당시 "약하다"고 했으나, 알코올이 낮고 신선해 **지금 재평가**되고 있다 |
| **편차가 작으므로 생산자를 먼저 볼 것** | 유럽만큼 빈티지에 매달릴 필요가 없다 |
