# 1. 헌터 밸리 Hunter Valley — 상식을 벗어난 산지

> 시드니 북쪽 160 km. **호주에서 가장 오래된 상업 산지(1820년대)**이면서, 와인 재배 조건으로는 **최악에 가깝다.**

| 항목 | 내용 |
|---|---|
| 위도 | **남위 32.8°** — 아열대 |
| 기후 | 덥고 습하다. **수확기(1~2월)에 비가 온다** |
| 문제 | 곰팡이병·부패 위험이 상시적 |
| 완화 요인 | 오후의 구름과 해풍이 열을 식힌다 |
| 품종 | **Semillon 세미용** · **Shiraz 시라즈** · Chardonnay · Verdelho |

## Hunter Semillon 헌터 세미용 — 세계 어디에도 없는 와인

| 항목 | 내용 |
|---|---|
| 수확 | **매우 일찍**(1월), 당도가 낮을 때 |
| 알코올 | **10~11%** — 세계 드라이 화이트 중 최저 수준 |
| 양조 | **오크 없음.** 스테인리스, 조기 병입 |
| 어릴 때 | 무색무취에 가깝다. 레몬·풀 정도 |
| **7~20년 뒤** | **토스트·꿀·구운 견과·라놀린**으로 완전히 변한다. 오크를 쓴 적이 없는데 토스트 향이 난다 |

> **오크 없이 토스트 향이 나는 이유** — 병 안에서 일어나는 환원적 숙성으로 생기는 향이다. 이 변화 때문에 헌터 세미용은 **"어릴 때 사서 10년 묵히는" 와인**으로 취급되며, 어린 것과 숙성된 것이 별개의 와인처럼 팔린다.

## Hunter Shiraz 헌터 시라즈

바로사와 정반대다. **알코올 13% 내외, 색이 옅고, 흙내·가죽·향신료**가 앞선다. 옛 문헌에서 "Hunter River Burgundy"라 불렸다.

**핵심 생산자**: **Tyrrell's 티렐스**(Vat 1 Semillon · Vat 47 Chardonnay) · **Brokenwood 브로큰우드**(Graveyard Shiraz) · **Mount Pleasant 마운트 플레전트**(Lovedale Semillon) · **Thomas Wines** · Meerea Park · Lake's Folly

> **Tyrrell's Vat 47**은 **호주 최초의 상업적 샤르도네**(1971)다. 지금 호주 샤르도네의 출발점.

# 3. 마거릿 리버 Margaret River

> 퍼스 남쪽 270 km, **삼면이 바다인 곶**. 호주 전체 생산량의 **3%에 불과한데 프리미엄 시장의 약 20%**를 차지한다.

| 항목 | 내용 |
|---|---|
| 개척 | **1965년 존 글래드스톤스 박사의 논문**이 이 지역을 보르도와 유사하다고 지목하면서 시작되었다. 1967년 첫 식재 |
| 기후 | **지중해성 해양성.** 인도양의 영향으로 연중 기온 변동이 매우 작다 |
| 토양 | 고대 화강암·편마암 위 자갈질 사양토 |
| 품종 | **Cabernet Sauvignon 카베르네 소비뇽** · **Chardonnay 샤르도네** · **Semillon-Sauvignon Blanc 블렌드(SSB)** |
| 위험 | 앵무새(!)와 바람. 우박은 드물다 |

| 스타일 | 성격 |
|---|---|
| **카베르네** | 보르도보다 완숙하나 **알코올은 절제**(13.5~14%). 카시스·삼나무·흑연. 20~30년 |
| **샤르도네** | 호주 최고 수준. **감귤·백도·부싯돌**, 오크 절제. 부르고뉴 코트드본과 비교된다 |
| **SSB** | 세미용 + 소비뇽 블랑 블렌드. 이 지역의 일상주이자 정체성 |

**핵심 생산자**: **Cullen 컬렌**(Diana Madeline — Langton's Exceptional, 비오디나미) · **Moss Wood 모스 우드** · **Vasse Felix 바스 펠릭스**(1967년 첫 와이너리) · **Leeuwin Estate 리우인 에스테이트**(Art Series Chardonnay) · **Pierro** · **Woodlands** · Xanadu · Voyager Estate

# 4. 그레이트 서던 Great Southern

> **호주 최대 면적 GI**(약 1.7만 km²)인데 포도밭은 흩어져 있다. 서호주 남단, 남극해에 면한다.

| 서브리전 | 성격 | 품종 |
|---|---|---|
| **Mount Barker 마운트 바커** | 서늘 | **Riesling 리슬링 · Shiraz** |
| **Frankland River 프랭클랜드 리버** | 내륙, 조금 따뜻 | Shiraz · Cabernet · Riesling |
| **Porongurup 포롱거럽** | 화강암 산지, 가장 서늘 | **Riesling** — 호주 최고 수준으로 평가 |
| **Denmark 덴마크** | 해안, 습윤 | Pinot Noir · Chardonnay |
| **Albany 올버니** | 해안 | Pinot Noir |

**핵심 생산자**: **Frankland Estate 프랭클랜드 에스테이트**(단일 밭 리슬링) · **Howard Park 하워드 파크** · **Plantagenet** · Castle Rock · Duke's

> **서호주 리슬링**은 클레어·에덴보다 덜 알려져 있으나, **포롱거럽·마운트 바커**의 것은 산도와 광물성에서 최고 수준으로 평가받는다.
