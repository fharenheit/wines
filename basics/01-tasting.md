# 마시는 법 — 테이스팅

> 테이스팅은 재능이 아니라 **절차**다. 같은 순서를 반복하면 누구나 는다. 순서를 지키는 이유는, 감각이 서로를 오염시키기 때문이다 — 향을 맡기 전에 마시면 향이 흐려지고, 색을 보기 전에 흔들면 정보가 사라진다.

## 1. 다섯 단계

| 단계 | 하는 일 | 걸리는 시간 |
|---|---|---|
| **① 본다** | 색의 농도·색조·가장자리 | 5초 |
| **② 맡는다 (흔들기 전)** | 첫 향. 결함은 여기서 대부분 잡힌다 | 5초 |
| **③ 흔들고 다시 맡는다** | 스월링 후 본향 | 15초 |
| **④ 마신다** | 구조 다섯 요소를 순서대로 | 20초 |
| **⑤ 삼킨 뒤 센다** | **여운의 길이를 초로 센다** | 10~30초 |

> **잔은 1/3 이하로 따른다.** 잔의 가장 넓은 지점까지가 상한이다. 그래야 흔들 수 있고, 흔들어야 향이 나온다. 레스토랑에서 잔을 적게 채워주는 것은 인색해서가 아니다.

---

## 2. ① 색

흰 종이나 흰 테이블보 위에 잔을 **45도로 기울여** 본다.

| 볼 것 | 무엇을 알려주나 |
|---|---|
| **농도** | 품종(피노 누아는 옅고 시라·말벡은 진하다) · 추출 강도 · 수확량 |
| **색조** | **레드**: 자주 → 루비 → 석류 → 벽돌 → 갈색 (나이가 들수록 오른쪽)<br>**화이트**: 연둣빛 → 밀짚 → 황금 → 호박 (나이가 들수록 오른쪽) |
| **가장자리(rim)** | 기울였을 때 얇게 퍼지는 테두리. **여기서 나이가 가장 잘 보인다** |
| 맑기 | 흐리면 무여과(natural) 또는 문제 |

> **레드는 나이 들며 옅어지고, 화이트는 나이 들며 진해진다.** 이 반대 방향이 색으로 나이를 읽는 핵심이다.

### 다리(legs / tears)에 대하여

잔 벽을 타고 내리는 줄기. **품질과 무관하다.** 알코올과 당도가 높으면 굵고 느리게 흐를 뿐이다(마랑고니 효과). 다리를 보고 좋은 와인이라고 말하는 사람이 있으면, 그 말만 믿지 않으면 된다.

---

## 3. ② ③ 향

### 왜 흔드는가

향기 성분은 휘발성이다. 스월링은 **표면적을 늘려 휘발을 촉진한다.** 흔들기 전과 후의 향이 다르다면, 그 차이 자체가 정보다.

> **흔들기 전에 한 번 맡는 습관을 들여라.** 코르크 냄새·산화 같은 결함은 흔들기 전에 가장 잘 드러난다.

### 향의 세 층

| 층 | 원어 | 출처 | 예 |
|---|---|---|---|
| **1차** | Primary 프라이머리 | **포도 자체** | 과일, 꽃, 허브, 후추 |
| **2차** | Secondary 세컨더리 | **양조 과정** | 효모·빵(샴페인), 버터(MLF), 오크·바닐라·토스트 |
| **3차** | Tertiary 터셔리 | **숙성** | 가죽, 버섯, 젖은 낙엽, 담배, 견과, 꿀 |

> **MLF(말로락틱 발효, Malolactic Fermentation)** — 날카로운 사과산(malic)을 부드러운 젖산(lactic)으로 바꾸는 2차 발효. 거의 모든 레드가 거치고, 샤르도네는 하느냐 마느냐로 스타일이 갈린다. **버터·크림 느낌**이 여기서 온다.

### 향을 말로 옮기는 요령

처음에는 구체적인 이름이 떠오르지 않는다. **범주부터 좁혀 들어간다.**

```
과일인가 아닌가
  └ 과일이면 → 붉은 과일 / 검은 과일 / 감귤 / 핵과 / 열대
        └ 신선한가 / 익었나 / 말랐나(건과)
  └ 과일이 아니면 → 꽃 / 허브 / 향신료 / 나무 / 흙 / 동물성 / 빵·효모
```

**"붉은 과일, 신선함"**까지만 말해도 충분한 테이스팅 노트다. 딸기인지 라즈베리인지는 나중 문제다.

### 품종별 대표 향 (기억의 닻)

| 품종 | 이것이 나면 의심하라 |
|---|---|
| **Sauvignon Blanc 소비뇽 블랑** | 자몽·풀·고양이 오줌·패션프루트 |
| **Riesling 리슬링** | 라임·백도·**휘발유(숙성 시)** |
| **Chardonnay 샤르도네** | 무향에 가깝다 → 오크·버터가 있으면 신세계, 없고 짜면 샤블리 |
| **Gewürztraminer 게뷔르츠트라미너** | 리치·장미·생강 |
| **Pinot Noir 피노 누아** | 딸기·체리·흙·버섯. **색이 옅다** |
| **Cabernet Sauvignon 카베르네 소비뇽** | 카시스·민트·삼나무·연필심 |
| **Syrah 시라** | **흑후추**·올리브·베이컨 |
| **Nebbiolo 네비올로** | 장미·타르·체리. **색은 옅은데 탄닌은 강하다**(가장 헷갈리는 품종) |
| **Sangiovese 산조베제** | 신 체리·토마토·가죽 |
| **Malbec 말벡** | 자두·제비꽃·코코아 |
| **Grüner Veltliner 그뤼너 벨트리너** | 흰 후추·완두콩 |

## 4. ④ 맛 — 구조 다섯 요소

**한 모금을 입에 물고, 아래 순서대로 하나씩만 본다.** 한 번에 다 보려 하면 아무것도 못 본다.

| 요소 | 어디서 느끼나 | 확인법 | 척도 |
|---|---|---|---|
| **① 당도** | 혀끝, 첫 1초 | 삼킨 뒤 입술이 끈적한가 | 드라이 / 오프드라이 / 미디엄 / 스위트 |
| **② 산도** | 혀 옆면, 볼 안쪽 | **침이 얼마나 고이는가** | 낮음 / 중간 / 높음 |
| **③ 탄닌** (레드만) | 잇몸·혀 표면 | **입안이 마르고 조이는가** | 낮음 / 중간 / 높음 / 거친가 부드러운가 |
| **④ 알코올** | 목구멍, 삼킨 뒤 | **따뜻하거나 화끈한가** | 낮음(<12%) / 중간(12~13.5%) / 높음(>14%) |
| **⑤ 바디** | 입안 전체의 무게 | **탈지우유 / 우유 / 생크림** 중 무엇에 가까운가 | 라이트 / 미디엄 / 풀 |

> **산도와 탄닌을 혼동하는 것이 가장 흔한 실수다.**
> **산도 = 침이 고인다**(신 사과를 먹었을 때). **탄닌 = 입이 마른다**(진한 홍차나 감을 먹었을 때).
> 둘 다 "떫다"고 표현되지만 정반대의 감각이다.

### 다섯 요소 감 잡기 — 부엌에서 하는 실험

| 감각 | 이걸 먹어보라 |
|---|---|
| **높은 산도** | 레몬즙 한 방울 |
| **탄닌** | 진하게 우린 홍차, 떫은 감, 호두 속껍질 |
| **바디의 차이** | 탈지우유 → 일반우유 → 생크림을 차례로 한 모금씩 |
| **알코올의 열감** | 보드카 한 방울을 물에 타서 |

---

## 5. ⑤ 여운 (Finish)

삼킨 뒤 **입안에 맛이 남아 있는 시간을 초로 센다.** 가장 단순하면서 품질과 가장 잘 맞아떨어지는 지표다.

| 초 | 평가 |
|---|---|
| 3초 이하 | 짧다. 일상용 |
| 5~10초 | 보통 |
| 10~20초 | 좋다 |
| 20초 이상 | **뛰어나다** |

> 알코올의 화끈함은 여운이 아니다. **과일·꽃·향신료의 맛이 남아 있는 시간**을 센다.

---

## 6. 결론 — 네 가지만 적어라

| 항목 | 예 |
|---|---|
| **균형** | 어느 하나가 튀는가? (산이 너무 높다 / 알코올이 뜬다 / 오크가 과하다) |
| **복합성** | 향이 하나인가 여럿인가 |
| **여운** | 몇 초 |
| **지금 마실 만한가** | 지금 / 더 기다릴 것 / 늦었다 |

> 여기에 **"또 사겠는가?"** 한 줄을 붙이면 노트가 완성된다. 점수보다 이 한 줄이 오래 쓸모 있다.

---

## 7. 결함 — 이건 내 취향이 아니라 문제다

| 결함 | 냄새·맛 | 원인 | 어떻게 |
|---|---|---|---|
| **코르크 냄새 (TCA)** | **젖은 판지·곰팡이·젖은 개.** 과일 향이 사라진다 | 코르크 오염 물질 **TCA(트리클로로아니솔)** | **교환 대상.** 전체 병의 1~3%. 사람마다 감지 역치가 다르다 |
| **산화** | 마른 견과·갈변한 사과·셰리 냄새. 색이 갈색으로 | 산소 노출, 마개 불량, 오래된 병 | 교환 대상(의도된 스타일 제외) |
| **환원** | **성냥·삶은 양파·양배추·달걀** | 발효 중 황 화합물 | **결함이 아닐 수 있다.** 세게 스월링하거나 디캔팅하면 대개 사라진다 |
| **휘발산(VA)** | 매니큐어 리무버·식초 | 초산균 | 소량은 복합성, 과하면 결함 |
| **브레타노미세스 (Brett)** | **반창고·마구간·땀·훈제육** | 야생 효모 Brettanomyces | 소량은 "야성적"이라며 좋아하는 사람도 있다. 과하면 결함 |
| **열 손상** | 익은 잼 맛, 코르크가 밀려 나옴 | 유통·보관 중 고온 | 교환 대상 |
| **주석산 결정** | 잔에 뜨는 **투명한 유리 조각 같은 알갱이** | 주석산염 침전 | **결함이 아니다.** 무해하고 오히려 저온 처리를 덜 했다는 신호 |

> **"내 입에 안 맞는 것"과 "잘못된 병"은 다르다.** 위 표의 첫 두 줄(TCA·산화)만 확실히 구별할 수 있으면 충분하다.

## 8. 실전 습관

| 습관 | 이유 |
|---|---|
| **항상 두 병을 연다** | 비교가 없으면 배움이 없다. 반씩 마시고 진공 마개로 남긴다 |
| **같은 잔을 쓴다** | 잔이 다르면 비교가 성립하지 않는다 |
| **첫 잔과 마지막 잔을 비교한다** | 한 시간 사이의 변화가 그 와인의 잠재력을 말해준다 |
| **물과 무염 크래커를 곁에 둔다** | 세 잔째부터 미각이 무뎌진다 |
| **향수·립밤을 피한다** | 코가 먼저 죽는다 |
| **점수 대신 문장을 적는다** | "88점"은 6개월 뒤 아무 의미가 없다. "산이 높고 여운이 짧았다"는 남는다 |
| **같은 와인을 다른 날 다시 마신다** | 컨디션·온도·안주에 따라 다르게 느껴진다는 것을 아는 게 중요하다 |

## 9. 용어 사전

| 용어 | 뜻 |
|---|---|
| **드라이 (Dry)** | 잔당이 거의 없다. **"쓰다"가 아니다** |
| **오프드라이 (Off-dry)** | 약간의 단맛. 리슬링 카비네트 등 |
| **바디 (Body)** | 입안에서 느껴지는 무게감 |
| **탄닌 (Tannin)** | 껍질·씨·줄기·오크에서 나오는 폴리페놀. **떫음과 구조** |
| **미네랄리티 (Minerality)** | 부싯돌·젖은 돌·소금 같은 느낌. **과학적으로 정의되지 않은 관습어**지만 널리 쓰인다 |
| **오크 (Oak)** | 바닐라·토스트·코코넛(미국 오크)·향신료(프렌치 오크) |
| **뉴 오크 (New oak)** | 새 통. 향이 강하게 밴다. 비싸다 |
| **MLF / 말로락틱** | 산을 부드럽게 바꾸는 2차 발효. 버터 느낌 |
| **쉬르 리 (Sur lie 쉬르 리)** | 죽은 효모(리) 위에서 숙성. **빵·크림 질감** |
| **바토나주 (Bâtonnage 바토나주)** | 리를 휘저어 주는 작업 |
| **껍질 접촉 (Skin contact)** | 화이트 품종을 껍질과 함께 침용 → **오렌지 와인** |
| **탄산 침용 (Carbonic maceration)** | 포도알을 통째로 무산소 발효. **보졸레의 바나나·풍선껌 향** |
| **크뤼 (Cru 크뤼)** | 밭 또는 등급 단위. 지역마다 뜻이 다르다 |
| **테루아 (Terroir 테루아)** | 토양·기후·지형·인간 관행의 총체 |
| **빈티지 (Vintage)** | **수확 연도.** 병에 든 해가 아니다 |
| **논빈티지 (NV)** | 여러 해를 섞음. 샴페인의 기본형 |
| **디캔팅 (Decanting)** | 다른 용기로 옮김. → [서빙 문서](02-serving.md) |
| **브리딩 (Breathing)** | 공기와 접촉시켜 여는 것. **코르크만 뽑아두는 것은 효과가 거의 없다** |
| **레그 / 티어 (Legs)** | 잔 벽의 줄기. **품질과 무관** |
| **클로징 / 닫힘 (Closed)** | 숙성 중간에 향이 일시적으로 사라지는 시기 |
| **여운 (Finish)** | 삼킨 뒤 맛이 남는 시간 |
| **밸런스 (Balance)** | 다섯 요소 중 튀는 것이 없는 상태. **가장 중요한 평가어** |
