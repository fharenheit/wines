## 1. 라벨 읽는 순서 — 5초 안에

| 순서 | 볼 것 | 알 수 있는 것 |
|---|---|---|
| **①** | **나라 / 지역명** | 스타일의 8할. `Chablis`만 봐도 무오크 샤르도네다 |
| **②** | **품종** (있으면) | 신세계는 대개 표기, **구세계는 대개 없다** |
| **③** | **빈티지** | 화이트·로제는 최신이 좋다. 레드는 → [빈티지 차트](../vintages/00-guide.md) |
| **④** | **알코올 도수** | **가장 저평가된 정보.** 12%면 서늘하고 마른 스타일, 15%면 덥고 진한 스타일 |
| **⑤** | 등급 표기 | AOC · DOCG · DO · Prädikat 등 |
| **⑥** | **생산자 이름** | 결국 이것이 가장 중요하다 |
| ⑦ | 병입 표기 | `Mis en bouteille au château/domaine` = **직접 병입**(대개 좋은 신호) |

> **구세계 라벨에 품종이 없는 이유** — 프랑스·이탈리아는 **산지가 곧 품종을 규정**하기 때문이다. `Sancerre`라고 쓰면 소비뇽 블랑이고, `Barolo`라고 쓰면 네비올로다. 그래서 이 저장소의 지역 문서에는 전부 **「품종」 절**이 있다.

### 알코올 도수로 읽는 스타일

| 도수 | 대개 |
|---|---|
| 8~11% | 잔당이 있는 화이트(**독일 리슬링**) 또는 모스카토 |
| 11.5~12.5% | 서늘한 기후. 산도 높고 가볍다 |
| 13~14% | 표준 |
| **14.5% 이상** | **더운 기후 또는 늦수확.** 진하고 무겁다. 여운에서 열감 |
| 15~22% | 주정강화(포트·셰리·마데이라) |

### 자주 마주치는 라벨 용어

| 표기 | 뜻 |
|---|---|
| **Réserve / Reserve** | **프랑스·미국·칠레에서는 법적 의미가 없다.** 마케팅 용어 |
| **Reserva / Gran Reserva**(스페인) · **Riserva**(이탈리아) | **법적 최소 숙성 기간이 정해져 있다** |
| **Vieilles Vignes 비에유 비뉴** | 노목. **법적 기준 없음** |
| **Old Vine / Alte Reben** | 노목. 역시 대개 기준 없음 |
| **Sec / Trocken / Seco / Dry** | 드라이 |
| **Demi-sec / Halbtrocken / Semi-seco** | 오프드라이 |
| **Brut** | 스파클링의 드라이 (0~12g/L) |
| **Extra Brut / Brut Nature** | 더 드라이 (Nature는 당 첨가 없음) |
| **Blanc de Blancs** | 청포도만으로 만든 스파클링 |
| **Blanc de Noirs** | **흑포도로 만든 화이트** |
| **NV / Sans Année** | 논빈티지(여러 해 블렌딩) |
| **Estate / Domaine / Château** | 자기 밭 |
| **Négociant 네고시앙** | 포도·와인을 사서 만드는 회사 |
| **Cuvée 퀴베** | 특정 배합·구획. **등급 표시가 아니다** |
| **Unfiltered / Non filtré** | 무여과. 흐릴 수 있다 |
| **Contains Sulfites** | **모든 와인에 있다.** 경고가 아니라 표시 의무 |

## 2. 어디서 사나

| 경로 | 장점 | 단점 |
|---|---|---|
| **대형마트** | 싸다. 접근성 | 품목이 한정적, **보관 상태 편차**(조명·온도) |
| **와인 전문점** | **상담이 가능하다** — 초보에게 가장 좋다 | 조금 비싸다 |
| **온라인 주문 → 매장 픽업** | 국내 주류는 온라인 배송이 제한되어 **스마트오더 방식**이 일반적. 가격 비교가 쉽다 | 실물 확인 불가 |
| 백화점 | 품목이 넓고 상태가 좋다 | 비싸다 |
| **면세점** | 고가대가 유리 | 저가대는 이점이 적다 |
| 해외 직접 구매 | 가격 | **주세·통관 한도** 확인 필요 |

### 매장에서 확인할 것

| 확인 | 왜 |
|---|---|
| **직사광선·스포트라이트 아래 서 있는 병은 피한다** | 열과 자외선 |
| **코르크가 밀려 올라온 병은 피한다** | 열 손상의 신호 |
| 액면(ullage)이 어깨 아래로 내려간 오래된 병 | 증발·누출 |
| 라벨 얼룩 | 누출 흔적일 수 있다 |
| **회전이 빠른 매장인가** | 재고가 오래 서 있지 않는 곳이 좋다 |

### 점원에게 이렇게 물어라

**"어떤 와인이 좋아요?"는 답하기 어려운 질문이다.** 대신 세 가지를 준다.

```
① 예산      : "$25 정도에서"
② 상황·음식 : "오늘 저녁에 삼겹살이랑"
③ 취향의 방향: "지난번에 말버러 소비뇽 블랑이 좋았어요"
              또는 "떫은 건 아직 어려워요"
```

> **③이 가장 강력하다.** 좋았던 와인 한 병의 이름을 기억해 가면, 그로부터 확장해 줄 수 있다. 그래서 **[테이스팅 노트](01-tasting.md#8-실전-습관)**를 쓰는 것이 실용적이다.

## 가격 표기에 대하여

> **이 저장소의 가격은 모두 미국 소매 기준 USD다.**

한국 소매가를 하나의 숫자로 적기 어렵기 때문이다 — 같은 와인이 수입사·유통 경로·행사 여부에 따라 두 배 넘게 벌어지고, 아예 들어오지 않는 와인도 많다. **미국 소매가는 비교적 안정적이라 기준점으로 쓰기 좋다.**

### 한국 가격으로 옮기려면

| 단계 | 내용 |
|---|---|
| **관세** | 15%. 다만 **FTA 체결국(EU · 미국 · 칠레 · 호주 · 뉴질랜드 등)은 0%** |
| **주세** | **30%** (과세가격 + 관세 기준) |
| **교육세** | 주세액의 **10%** |
| **부가세** | (과세가격 + 관세 + 주세 + 교육세)의 **10%** |
| 그다음 | 수입사 · 도매 · 소매 마진이 차례로 붙는다 |

세금만으로 통관 원가의 **약 46%**가 더해지고, 여기에 유통 마진이 얹힌다.

### 실무적인 어림값

| | 한국 소매가 |
|---|---|
| **저가대**($10~25) | 미국 소매가의 **2~2.5배** — 세금과 물류의 고정비 비중이 커서 배수가 가장 크다 |
| **중가대**($25~80) | **1.7~2.2배** |
| **고가대**($100 이상) | **1.3~1.8배** — 배수는 줄지만 절대 금액 차이는 커진다 |
| 면세점 | 고가대에서 유리하다. 저가대는 이점이 적다 |

> **예외가 많다.** 대량 수입되는 브랜드는 마트 행사에서 미국보다 싸게 나오기도 하고, 희소한 와인은 배수가 3배를 넘기도 한다. **위 배수는 감을 잡기 위한 것이지 계산식이 아니다.**

## 3. 가격대별 전략

| 가격대 | 잘 되는 곳 | 피할 곳 |

| **$12~25** | **가성비의 핵심 구간** — 스페인(리오하 크리안사) · 이탈리아(키안티·발폴리첼라) · 칠레 · 아르헨티나 · 포르투갈 · 남아공 | |
| **$25~50** | 루아르 · 론 · 알자스 · 독일 리슬링 · 뉴질랜드 · **크레망·카바** | 이 가격대의 부르고뉴·샴페인은 애매하다 |

### 비싸지는 이유들

| 이유 | 값어치가 있나 |
|---|---|
| 생산량이 적은 밭 | **대체로 그렇다** |
| 낮은 수확량·손 수확 | 그렇다 |
| 새 오크 통 | 스타일의 문제 |
| **평론가 점수** | **가격을 크게 밀어올린다.** 값어치와는 별개 |
| **브랜드·희소성·투자 수요** | 마시는 즐거움과 무관한 부분이 크다 |
| 무거운 병·화려한 포장 | **역의 신호일 때가 많다** |

## 4. 레스토랑에서

### 주문 절차

| 순서 | 할 일 |
|---|---|
| 1 | 와인 리스트를 받으면 **예산을 먼저 정한다** |
| 2 | **가격을 손가락으로 짚으며** "이 정도에서 추천해 주세요"라고 한다. 소리 내어 금액을 말할 필요가 없다 |
| 3 | 음식 주문을 먼저 하거나 함께 말한다 |
| 4 | 병이 오면 **라벨을 확인한다** — 내가 주문한 것, 그 빈티지가 맞는지 |
| 5 | 코르크를 건네주면 **냄새를 맡지 말고 그냥 둔다** (촉촉한지 정도만 보면 된다) |
| 6 | **호스트 테이스팅** — 한 모금 |
| 7 | 괜찮으면 고개를 끄덕인다 |

> **호스트 테이스팅의 목적은 "맛있는지"가 아니라 "상했는지"다.**
> 돌려보낼 수 있는 경우: **코르크 냄새(젖은 판지) · 산화 · 열 손상 · 주문과 다른 병.**
> 돌려보낼 수 없는 경우: **"생각보다 제 취향이 아니네요."**
> 애매하면 이렇게 말한다 — **"이 와인이 원래 이런 향인가요? 좀 확인해 주시겠어요?"** 대부분의 업장이 기꺼이 확인해 준다.

### 알아둘 것

| 항목 | 내용 |
|---|---|
| **마크업** | 레스토랑 와인은 소매가의 **2~3배**가 일반적이다 |
| **하우스 와인** | 나쁘지 않다. 가격 대비 무난한 선택 |
| **글라스 와인** | 2~3잔 마실 거면 **병이 대개 더 싸다** |
| **코르키지(Corkage)** | 가져간 와인의 개봉료. **업장마다 정책이 다르니 반드시 미리 확인**한다. 무료인 곳도 있다 |
| **가져갈 때의 예의** | 그 업장 리스트에 있는 와인은 피한다. 소믈리에에게 한 잔 권하는 것이 관례 |
| **남은 병** | 국내에서도 재마개 후 가져가는 것을 허용하는 업장이 있다. 물어보면 된다 |
| **온도** | **레드가 미지근하면 아이스버킷을 요청해도 된다.** 무례하지 않다 |

## 5. 사기 전 확인할 수 있는 것

| 도구 | 용도 |
|---|---|
| **Vivino 비비노** | 라벨 사진으로 검색. **일반 사용자 평점** — 대중적 취향에 치우치지만 지뢰는 피할 수 있다 |
| **Wine-Searcher 와인서처** | **국제 시세 비교.** 지금 보는 가격이 적정한지 판단 |
| **CellarTracker 셀러트래커** | 애호가들의 상세 노트. 마시기 좋은 시기 판단에 유용 |
| 평론가 점수 | 로버트 파커(RP)·와인 스펙테이터(WS)·잰시스 로빈슨(JR, **20점 만점**)·앙투안 갈로니 |

> **점수를 어떻게 볼 것인가** — 평론가마다 좋아하는 스타일이 다르다. 파커 계열의 고득점은 대개 **진하고 오크가 강한 스타일**이고, 잰시스 로빈슨은 **절제된 스타일**에 후하다. **90점이라는 숫자보다, 그 점수를 준 사람이 나와 취향이 맞는지**가 중요하다.

## 6. 처음 사기 좋은 10병

한 번에 다 살 필요는 없다. **각 방향의 기준점**이 되는 병들이다.

| # | 와인 | 왜 |
|---|---|---|
| 1 | **말버러 소비뇽 블랑** | 높은 산도의 기준 |
| 2 | **샤블리** | 무오크 샤르도네의 기준 |
| 3 | **독일 리슬링 카비네트** | 잔당과 산도의 균형 |
| 4 | **보졸레 빌라주** | 가벼운 레드. **차게 마시는 레드** |
| 5 | **키안티 클라시코** | 산도 있는 미디엄 레드 |
| 6 | **리오하 크리안사** | 오크 숙성 레드의 기준. 가성비 |
| 7 | **칠레·호주 카베르네** | 탄닌의 기준 |
| 8 | **아르헨티나 말벡** | 풀바디의 기준 |
| 9 | **카바 또는 크레망** | 전통 방식 스파클링 |
| 10 | **셰리 피노 (하프보틀)** | 완전히 다른 세계 |

> 이 10병이 곧 **[12주 코스](03-course.md)**의 절반이다.
