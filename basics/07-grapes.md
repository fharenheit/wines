# 포도 품종별 특징

> 품종은 와인을 이해하는 **첫 번째 좌표**다. 다만 유일한 좌표는 아니다 — [12주 코스 2주차](03-course.md#2주차--오크)에서 보듯 같은 샤르도네가 양조 방식만으로 완전히 달라지고, [6주차](03-course.md#6주차--같은-품종-다른-땅-화이트)에서 보듯 같은 소비뇽 블랑이 땅에 따라 다른 와인이 된다.
>
> 그래서 이 문서는 **"이 품종은 이런 맛"**이 아니라 **"이 품종은 이런 경향이 있고, 어디서 어떻게 벗어나는가"**로 정리했다.

## 품종을 읽는 네 축

| 축 | 무엇을 결정하나 |
|---|---|
| **산도** | 개운함·숙성력·음식과의 궁합. 서늘한 기후일수록 높다 |
| **탄닌** (레드) | 구조·숙성력·고기와의 궁합. **껍질이 두꺼울수록 높다** |
| **바디** | 입안의 무게. 알코올·추출·잔당이 함께 만든다 |
| **향의 강도** | 품종 자체의 개성. **강한 품종**(게뷔르츠트라미너)과 **중립적 품종**(샤르도네)이 있다 |

> **중립적 품종일수록 땅과 양조가 드러난다.** 샤르도네·슈냉 블랑이 세계 각지에서 전혀 다른 와인이 되는 이유이고, 게뷔르츠트라미너가 어디서 만들어도 게뷔르츠트라미너인 이유다.

# 화이트 품종

## Sauvignon Blanc 소비뇽 블랑

| | |
|---|---|
| **한 줄** | **산도가 무엇인지 배우기에 가장 좋은 품종** |
| **향** | 자몽 · 라임 · 풀 · 피망 · 구스베리 · 패션프루트 · "고양이 오줌" |
| **구조** | 산도 **높음** · 바디 라이트 · 알코올 12~13.5% · 오크 대개 없음 |
| **어디서** | **루아르**(상세르·푸이퓌메 — 절제·부싯돌) · **말버러**(폭발적 열대 과일) · 보르도(세미용과 블렌딩) · 칠레 레이다 · 남아공 |
| **온도·음식** | 8~10℃ · 샐러드 · 염소 치즈 · 굴 · **아스파라거스**(거의 유일한 해답) |
| **입문 한 병** | 말버러 소비뇽 블랑 ($15~25) |

> **향의 정체** — 풀·피망 냄새는 **피라진(pyrazine)**, 패션프루트·자몽은 **티올(thiol)**이라는 성분이다. 서늘하거나 덜 익으면 피라진이, 잘 익으면 티올이 우세해진다. 상세르와 말버러의 차이가 대체로 이 비율이다.
>
> 예외: **푸메 블랑(Fumé Blanc)**은 오크를 쓴 소비뇽 블랑이다. 완전히 다른 와인처럼 느껴진다.

**→ [루아르](../france/05-loire.md) · [뉴질랜드](../newzealand/00-overview.md) · [칠레 해안](../chile/02-coastal-south.md)**

## Chardonnay 샤르도네

| | |
|---|---|
| **한 줄** | **가장 중립적인 화이트.** 그래서 양조가와 땅이 그대로 드러난다 |
| **향** | 품종 자체는 **거의 무향**. 서늘하면 레몬·사과·분필, 따뜻하면 복숭아·파인애플 |
| **구조** | 산도 중~높음 · 바디 미디엄~풀 · 알코올 12.5~14% |
| **양조가 만드는 것** | **오크** → 바닐라·토스트 · **MLF** → 버터 · **쉬르 리** → 빵·크림 |
| **어디서** | **부르고뉴**(샤블리~뫼르소~몽라셰) · **샴페인**(블랑 드 블랑) · 캘리포니아 · 호주 · **칠레 리마리**(석회질) |
| **온도·음식** | 10~13℃ · 버터 소스 생선 · 닭 · 게 · 삼계탕 |
| **입문 한 병** | **샤블리 + 신세계 오크 샤르도네를 동시에** (→ [2주차](03-course.md#2주차--오크)) |

> **"ABC(Anything But Chardonnay)"** — 1990년대 과도한 오크 사용에 대한 반작용으로 나온 말이다. 지금은 오크를 크게 줄이는 흐름이라 그때의 편견은 유효하지 않다.

**→ [샤블리·샬로네즈·마코네](../france/02-3-chablis-chalonnaise-maconnais.md) · [코트드본](../france/02-2-cote-de-beaune.md)**

## Riesling 리슬링

| | |
|---|---|
| **한 줄** | **많은 전문가가 최고의 화이트 품종으로 꼽는다.** 그런데 가장 저평가되어 있다 |
| **향** | 라임 · 청사과 · 백도 · 꿀 · **휘발유(숙성 시)** · 흰 꽃 |
| **구조** | 산도 **매우 높음** · 바디 라이트 · **알코올 7.5~12%** · **오크 쓰지 않는다** |
| **당도** | **드라이부터 극단적 스위트까지 전부.** 라벨을 봐야 안다 |
| **어디서** | **모젤**(가볍고 짜릿) · 라인가우 · **알자스**(대개 드라이·묵직) · **클레어/에덴 밸리**(라임·드라이) · 워싱턴 · 핑거레이크스 |
| **온도·음식** | 8~10℃ · **매운 음식의 최고 해답** · 돼지고기 · 아시아 요리 전반 |
| **입문 한 병** | 모젤 리슬링 **카비네트** ($25~40) |

> **휘발유 향(TDN)** — 숙성된 리슬링에서 나는 이 향은 **결함이 아니라 품질의 증표**로 여겨진다. 강한 일조와 병 숙성에서 생긴다.
>
> **당도를 라벨에서 읽는 법**: `Trocken`=드라이 · `Halbtrocken/Feinherb`=오프드라이 · 표기 없는 `Kabinett/Spätlese`=대개 약간 달다. → [독일 개요](../germany/00-overview.md)

## Chenin Blanc 슈냉 블랑

| | |
|---|---|
| **한 줄** | **한 품종으로 스파클링·드라이·스위트를 모두 만드는 유일한 수준의 품종** |
| **향** | 사과 · 모과 · 꿀 · 카모마일 · **젖은 양모 · 라놀린** |
| **구조** | 산도 **매우 높음** · 바디 미디엄 · 숙성력이 놀랍다(30년 이상) |
| **어디서** | **부브레**(드라이~스위트~스파클링) · **사브니에르**(드라이·강건) · 코토 뒤 레용(스위트) · **남아공**(현지명 **Steen 스틴** — 최대 재배국) |
| **온도·음식** | 9~11℃ · 돼지고기 · 크림 소스 · 매운 음식(오프드라이) |
| **입문 한 병** | 부브레 Sec 또는 남아공 슈냉 ($20~35) |

> **가성비가 가장 좋은 화이트 중 하나다.** 특히 남아공 슈냉은 품질 대비 값이 낮다.

## Pinot Gris / Pinot Grigio 피노 그리 / 피노 그리지오

| | |
|---|---|
| **한 줄** | **같은 품종, 두 개의 인격** |
| **이탈리아식 (Grigio)** | 중립적 · 가볍다 · 산도 중간 · 레몬·배. **무난하고 심심하다** |
| **알자스식 (Gris)** | 풍만 · 향신료 · 훈연 · **잔당이 있는 경우가 많다** · 알코올 13.5~14% |
| **어디서** | 이탈리아 북동부 · **알자스** · 오리건(알자스 쪽에 가깝다) · 독일(Grauburgunder) |
| **온도·음식** | 9~11℃ · (그리지오) 가벼운 전채 · (그리) 돼지고기·푸아그라·알자스 요리 |

> 라벨에 `Pinot Grigio`인지 `Pinot Gris`인지가 스타일을 알려주는 신호로 굳어졌다. 껍질이 회분홍색이라 **껍질 접촉을 하면 구릿빛(ramato 라마토) 로제**가 나온다.

## Gewürztraminer 게뷔르츠트라미너

| | |
|---|---|
| **한 줄** | **가장 알아맞히기 쉬운 품종.** 한 번 맡으면 잊지 않는다 |
| **향** | **리치 · 장미 · 생강 · 향신료**(Gewürz = 독일어로 "향신료") |

| **어디서** | **알자스** · 알토아디제 · 독일 · 뉴질랜드 · 칠레 카사 마린 |

## Sémillon 세미용

| | |
|---|---|
| **한 줄** | **어릴 땐 밋밋하고, 늙으면 놀랍다** |
| **향** | 레몬 · 밀랍 · 라놀린 · (숙성) 토스트 · 꿀 |
| **구조** | 산도 중간 · 바디 미디엄~풀 · **껍질이 얇아 귀부병에 잘 걸린다** |

# 구조로 줄 세우기

## 산도 — 높은 순

| 화이트 | 레드 |
|---|---|
| **리슬링 · 슈냉 블랑 · 아시르티코** | **네비올로 · 산조베제** |
| 소비뇽 블랑 · 알바리뇨 · 그뤼너 | 바르베라 · 피노 누아 · 가메 |
| 샤르도네(서늘) · 세미용 | 카베르네 프랑 · 템프라니요 |
| 샤르도네(따뜻) · 피노 그리지오 | 카베르네 소비뇽 · 시라 · 말벡 |
| **비오니에 · 게뷔르츠트라미너** | **그르나슈 · 진판델** |

## 탄닌 — 높은 순 (레드)

```
네비올로 · 타나  >  카베르네 소비뇽 · 아글리아니코 · 무르베드르
                 >  시라 · 산조베제 · 말벡 · 템프라니요
                 >  메를로 · 카베르네 프랑 · 진판델
                 >  피노 누아 · 그르나슈 · 바르베라
                 >  가메 · 시나울트 · 파이스
```

## 바디 — 무거운 순

| | 화이트 | 레드 |
|---|---|---|
| **풀** | 오크 샤르도네 · 비오니에 · 게뷔르츠트라미너 | 카베르네 · 시라(호주) · 말벡 · 진판델 · 그르나슈 |
| **미디엄** | 샤르도네(무오크) · 슈냉 · 피노 그리(알자스) | 메를로 · 산조베제 · 템프라니요 · 네비올로 · 시라(론) |
| **라이트** | 리슬링 · 소비뇽 블랑 · 알바리뇨 · 피노 그리지오 | 피노 누아 · 가메 · 바르베라 · 파이스 |

> **네비올로가 미디엄 바디인데 탄닌은 최고**라는 점이 이 표의 핵심이다. **바디와 탄닌은 별개의 축이다.**

# 헷갈리는 쌍 — 구별하는 한 가지

| 쌍 | 구별점 |
|---|---|
| **피노 누아 vs 네비올로** | 둘 다 색이 옅다. **네비올로는 입이 확 마른다**(탄닌). 그리고 **장미·타르** 향 |
| **가메 vs 피노 누아** | 가메가 더 즙이 많고 단순하다. **바나나·풍선껌**이 나면 가메(탄산 침용) |
| **카베르네 소비뇽 vs 메를로** | 카베르네는 **민트·연필심**에 각지고, 메를로는 자두에 둥글다 |
| **시라 vs 쉬라즈** | **알코올 도수를 본다.** 13%대면 론, 14.5% 이상이면 호주 |
| **산조베제 vs 템프라니요** | 산조베제는 **토마토·신 체리**, 템프라니요는 **가죽·딜·바닐라** |
| **샤르도네 vs 슈냉 블랑** | **슈냉의 산도가 훨씬 높다.** 그리고 젖은 양모 향 |
| **소비뇽 블랑 vs 그뤼너** | 그뤼너는 **흰 후추와 완두콩**, 소비뇽은 자몽·풀 |
| **리슬링 vs 소비뇽 블랑** | 리슬링은 **알코올이 낮고**(9~12%) 대개 잔당이 있다 |
| **말벡 vs 시라** | 말벡은 **제비꽃·코코아**에 탄닌이 부드럽고, 시라는 **후추**가 난다 |
| **카르메네르 vs 메를로** | 카르메네르에서 **피망·간장** 향이 난다 |

> **블라인드에서 품종을 맞추려 하지 마라.** [12주 코스 12주차](03-course.md#12주차--블라인드)에서 말했듯, 산도·탄닌·바디·오크·알코올 다섯 가지를 틀리지 않게 말하는 것이 훨씬 유용하다.
