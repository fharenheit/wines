# 다루는 법 — 온도 · 잔 · 개봉 · 보관

> **같은 와인도 온도가 5℃ 다르면 다른 와인이 된다.** 초보자가 가장 빨리, 가장 크게 개선할 수 있는 변수는 지식이 아니라 온도다.

## 1. 온도 — 가장 중요한 한 가지

| 스타일 | 온도 | 냉장고에서 |
|---|---|---|
| **셰리 피노·만사니야** | **6~8℃** | 꺼내자마자 |
| **스파클링** (샴페인·카바·프로세코) | **6~10℃** | 꺼내자마자 |
| **가벼운 화이트** (소비뇽 블랑·피노 그리지오·뮈스카데) | **8~10℃** | 꺼내자마자 |
| **풀바디 화이트** (오크 샤르도네·화이트 부르고뉴·론 화이트) | **10~13℃** | 꺼내고 **15분** |
| **스위트 와인** (소테른·아이스바인) | **8~12℃** | 꺼내고 10분 |
| **로제** | **8~12℃** | 꺼내고 10분 |
| **가벼운 레드** (보졸레·피노 누아·발폴리첼라·파이스) | **12~14℃** | **냉장고에 30~40분 넣었다가** |
| **미디엄 레드** (키안티·리오하·메를로) | **14~16℃** | 냉장고에 20~30분 |
| **풀바디 레드** (카베르네·시라·바롤로·말벡) | **16~18℃** | 냉장고에 15~20분 |
| **포트·마데이라** | 14~16℃ | 냉장고에 20분 |

> **"레드는 실온"이라는 말의 함정** — 이 말(**chambré 샹브레**)이 만들어진 19세기 유럽 저택의 실온은 **16~18℃**였다. 한국의 여름 실내는 25~28℃다. **그 온도의 레드는 알코올만 튀고 향이 무너진다.**

### 한 문장 규칙

> **레드는 생각보다 차갑게, 화이트는 생각보다 덜 차갑게.**

- 레드가 25℃라면 → **냉장고 20~30분**
- 화이트를 냉장고에서 막 꺼냈다면 → **10~15분 두었다가**

### 온도가 하는 일

| 온도를 낮추면 | 온도를 높이면 |
|---|---|
| 산도와 탄닌이 **도드라진다** | 향이 **열린다** |
| 향이 닫힌다 | 알코올이 **튄다** |
| 단맛이 덜 느껴진다 | 단맛과 바디가 커진다 |
| **결함이 가려진다** | **결함이 드러난다** |

> **싼 와인은 조금 더 차갑게, 좋은 와인은 조금 더 따뜻하게.** 그래서 저가 화이트를 아주 차갑게 내는 것은 합리적인 선택이다.

### 급속 냉각

| 방법 | 시간 |
|---|---|
| **얼음물 + 소금 한 줌**(병을 목까지 담근다) | **10~15분에 20℃ → 8℃** |
| 냉장고 | 2~3시간 |
| 냉동실 | 20분(**절대 잊으면 안 된다**. 터진다) |
| 젖은 키친타월로 감싸 냉동실 | 15분 |

## 2. 잔

### 잔이 실제로 하는 일

| 부위 | 역할 |
|---|---|
| **볼(bowl)의 크기** | 향이 모이는 공간. 클수록 향이 많이 나온다 |
| **입구가 좁아지는 형태** | **향을 가둔다.** 튤립형이 기본인 이유 |
| **얇은 림(rim)** | 입술에 걸리는 이물감을 줄인다 |
| **스템(다리)** | **손의 체온이 와인에 전달되지 않게 한다** |

> **잔은 스템을 잡는다.** 볼을 감싸 쥐면 10분 만에 2~3℃가 오른다. (예외: 아주 차가운 화이트를 조금 데우고 싶을 때는 일부러 볼을 잡기도 한다.)

### 몇 개가 필요한가

| 단계 | 구성 |
|---|---|
| **최소** | **범용 튤립 잔(ISO 표준형) 2개** — 이걸로 전부 된다 |
| 다음 | **레드용 큰 잔 2개** 추가 |
| 그다음 | 부르고뉴형(볼록한) 2개 |

### 대표 형태

| 형태 | 특징 | 무엇에 |
|---|---|---|
| **보르도형** | 길고 큰 튤립 | 카베르네·시라·말벡 — **탄닌이 강한 레드** |
| **부르고뉴형** | 넓고 볼록, 입구가 좁다 | **피노 누아·네비올로** — 향이 섬세한 레드 |
| **화이트형** | 작은 튤립 | 대부분의 화이트 |
| **플루트(길쭉)** | 기포가 예쁘다 | 스파클링 — **다만 향이 안 열린다** |
| **쿠프(넓고 얕은)** | 장식용 | 기포와 향이 둘 다 날아간다. **쓰지 말 것** |

> **샴페인은 플루트보다 화이트 잔이 낫다.** 좋은 샴페인일수록 그렇다. 기포를 보는 즐거움을 버리는 대신 **향을 얻는다.** 최근 샴페인 하우스들도 튤립형을 권한다.

### 씻는 법

| 하라 | 하지 마라 |
|---|---|
| **뜨거운 물로만** 헹구고 뒤집어 말린다 | 향이 강한 세제 |
| 마른 극세사 천으로 물자국 제거 | 젖은 채 찬장에 엎어두기(**갇힌 냄새**) |
| 처음 쓰기 전 한 번 헹군다 | 종이 상자 안에 오래 보관 |

> **잔에서 나는 곰팡이·찬장 냄새를 와인 결함으로 착각하는 일이 흔하다.** 의심되면 다른 잔에 부어 다시 맡아본다.

## 3. 개봉

### 코르크

1. **캡슐(포일)을 병 입구 아래 턱에서 잘라낸다.** 위쪽만 잘라내면 따를 때 와인이 금속에 닿는다.
2. 스크루의 끝을 코르크 **정중앙**에 세우고 수직으로 돌려 넣는다.
3. **끝까지 넣지 않는다** — 관통하면 부스러기가 떨어진다.
4. 지렛대 첫 단을 걸고 절반, 두 번째 단을 걸고 나머지를 뺀다.
5. **마지막은 손으로 좌우로 흔들어 소리 없이 뽑는다.**

| 문제 | 해결 |
|---|---|
| **코르크가 부서진다** | 스크루를 **비스듬히** 넣어 남은 조각을 걸어 뺀다. 실패하면 병 안으로 밀어 넣고 걸러 따른다 |
| **코르크가 안 빠진다** (오래된 병) | 무리하지 말고 **아소(Ah-So, 두 갈래 날) 오프너** 사용 |
| 병 안에 조각이 떠 있다 | 커피 필터·고운 체로 거른다. 맛에는 지장 없다 |

### 스파클링 — 소리를 내지 않는다

1. **먼저 아주 차갑게 한다.** 미지근하면 압력이 높아 위험하다.
2. 포일을 벗기고 **철사(뮈즐레 muselet)를 푸는 순간부터 엄지로 코르크를 누른다.** 손을 떼지 않는다.
3. **병을 45도로 기울이고**, 코르크를 잡은 손은 고정한 채 **병을 돌린다.**
4. 압력을 손으로 버티며 **"쉬-" 하는 한숨 소리**로 뺀다.

> **펑 소리는 실패다.** 소리와 함께 거품과 향이 날아간다. 그리고 코르크는 시속 60km로 날아가 **실명 사고**를 낸다. 사람 없는 쪽으로 45도.

## 4. 디캔팅 — 목적이 두 가지다

**두 목적은 정반대의 판단을 요구한다.** 무엇을 하려는지 먼저 정해야 한다.

| 목적 | 대상 | 방법 |
|---|---|---|
| **① 침전물 분리** | **오래된 레드(10년 이상)** | 하루 전 세워둔다 → **아주 천천히** 한 번에 따른다 → 병목에 침전이 보이면 멈춘다. **공기 접촉은 최소로** |
| **② 산소 접촉(열어주기)** | **어리고 탄닌이 강한 레드**, 환원 냄새가 나는 와인 | 콸콸 부어 넣는다. 30분~2시간 둔다 |

### 판단표

| 와인 | 디캔팅 |
|---|---|
| 어린 보르도·바롤로·시라·말벡 (3~8년) | **1~2시간.** 크게 좋아진다 |
| 어린 부르고뉴 피노 | 30분 또는 하지 않음 |
| **20년 이상 된 와인** | **침전 분리만, 마시기 직전.** 오래 두면 30분 만에 무너진다 |
| 저가 레드 | 30분. 의외로 효과가 있다 |
| 화이트·스파클링 | 대개 불필요(오크 샤르도네·오렌지 와인은 예외) |
| 성냥·양파 냄새(환원) | **즉시 디캔팅.** 대부분 사라진다 |

> **"코르크만 미리 열어두면 된다"는 말은 사실상 틀렸다.** 병목 단면적으로 접촉하는 공기는 무시할 수준이다. 열어주려면 **잔에 따라 스월링하거나 디캔터에 옮겨야** 한다.
>
> **디캔터가 없으면** 깨끗한 유리 주전자·큰 유리병이면 된다. 급하면 **잔에 따라 두는 것**만으로도 상당한 효과가 있다.

## 5. 코스에서의 순서

여러 병을 열 때 순서를 지키면 각 와인이 제 실력을 낸다. **뒤로 갈수록 강해지게** 배치한다.

| 원칙 | 내용 |
|---|---|
| **거품 → 화이트 → 로제 → 레드** | |
| **가벼운 것 → 무거운 것** | 무거운 것 다음의 가벼운 와인은 물처럼 느껴진다 |
| **드라이 → 스위트** | 단 것을 먼저 마시면 다음 와인이 시고 마르게 느껴진다 |
| **어린 것 → 오래된 것** | 섬세한 노년 와인은 뒤에 |
| **싼 것 → 비싼 것** | |
| **낮은 알코올 → 높은 알코올** | |

### 전형적인 코스 배치

| 순서 | 자리 | 예 |
|---|---|---|
| 1 | 식전 | **샴페인 / 카바 / 스파클링** |
| 2 | 전채·해산물 | 가벼운 화이트 (소비뇽 블랑·뮈스카데·알바리뇨) |
| 3 | 생선·닭·크림 | 풀바디 화이트 (샤르도네) |
| 4 | 붉은 고기·파스타 | 미디엄 레드 (피노 누아·키안티) |
| 5 | 구이·스테이크 | 풀바디 레드 (카베르네·시라·바롤로) |
| 6 | 치즈 | 남은 레드 또는 **주정강화** |
| 7 | 디저트 | **스위트 와인 / 포트** |

> **예외: 오래된 섬세한 레드는 젊고 강한 레드보다 먼저 낸다.** "무거운 순서"보다 "섬세한 순서"가 우선이다. 40년 된 부르고뉴를 5년 된 나파 카베르네 뒤에 내면 아무 맛도 안 난다.

### 한 병에서 몇 잔이 나오나

| 기준 | 잔 수 |
|---|---|
| 750ml ÷ 125ml (레스토랑 표준) | **6잔** |
| 750ml ÷ 150ml (가정에서 넉넉히) | **5잔** |
| 테이스팅용 50ml | 15잔 |

**식사에 함께라면 1인당 1/3~1/2병**이 일반적인 계산이다.

## 6. 보관

### 장기 보관 (몇 년 이상)

| 조건 | 기준 | 왜 |
|---|---|---|
| **온도** | **12~14℃.** 무엇보다 **변동이 없을 것** | 온도가 오르내리면 코르크가 팽창·수축하며 공기가 드나든다 |
| **습도** | 60~75% | 낮으면 코르크가 마르고, 높으면 라벨에 곰팡이 |
| **자세** | **눕힌다**(코르크 마개) | 코르크를 적셔 밀봉을 유지 |
| **빛** | 어둡게 | 자외선이 **광 손상(goût de lumière)**을 일으킨다. 특히 스파클링·화이트 |
| **진동** | 없을 것 | 냉장고 압축기 위·세탁기 옆은 최악 |
| **냄새** | 강한 냄새 없는 곳 | 코르크는 숨을 쉰다. 김치냉장고 옆은 피한다 |

> **스크루캡은 세워 보관해도 된다.** 마를 코르크가 없다.

### 현실적인 대안

| 상황 | 어디에 |
|---|---|
| **몇 주~몇 달** | 집에서 가장 서늘하고 어둡고 온도 변화가 적은 곳 — **북향 벽면 아래쪽 붙박이장 바닥, 침대 밑** |
| 여름 | 일반 냉장고도 낫다(건조하지만 몇 달은 괜찮다) |
| 1년 이상 · 10병 이상 | **와인 셀러(12~15℃ 설정)** 또는 유료 보관 서비스 |

**피할 곳**: 주방 상부장(열), 베란다(온도 변동), 차 안(**여름 트렁크는 몇 시간 만에 와인을 죽인다**), 냉장고 문쪽(진동·개폐).

### 마시고 남은 병

| 방법 | 얼마나 |
|---|---|
| **코르크 다시 끼우고 냉장고** | 2~3일 (레드도 냉장고에. 마시기 전에 꺼내 온도를 올린다) |
| **진공 마개(와인 세이버)** | 3~5일 |
| **작은 병에 가득 옮겨 담기** | **5~7일.** 가장 효과가 좋다 — 공기 접촉 면적을 줄이는 것이 핵심 |
| 아르곤 가스 스프레이 | 1~2주 |
| **코라뱅(Coravin)** | 수개월 (고가 장비) |
| **스파클링 전용 스토퍼** | 1~2일 (일반 마개로는 하루도 못 간다) |

| 와인 | 남기고 다음 날 |
|---|---|
| 가벼운 화이트·로제 | 2~3일 괜찮다 |
| 오크 화이트 | 2~3일 |
| **탄닌 강한 레드** | **오히려 다음 날 더 좋은 경우가 많다** |
| 섬세한 노년 와인 | **당일에 마신다.** 다음 날이면 끝나 있다 |
| 스파클링 | 당일 |
| **셰리(피노)·주정강화** | 피노는 3~5일, 올로로소·포트는 **수주~수개월** |

> **남은 와인을 버리지 마라.** 요리용으로 훌륭하다. 얼음 틀에 얼려 두면 소스에 그대로 쓸 수 있다.
