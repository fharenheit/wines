# 음식과의 짝

> 페어링은 규칙이 아니라 **원리 몇 개와 지뢰 몇 개**다. 원리를 알면 처음 보는 음식에도 대응할 수 있고, 지뢰를 알면 최악은 피할 수 있다. 나머지는 취향이다.

## 1. 다섯 가지 원리

| # | 원리 | 내용 | 예 |
|---|---|---|---|
| **①** | **무게를 맞춘다** | 가벼운 음식엔 가벼운 와인. **가장 중요하고 가장 자주 어긋나는 원칙** | 굴 ↔ 뮈스카데 / 갈비 ↔ 시라 |
| **②** | **산도는 산도로 받는다** | 음식의 산도가 와인보다 높으면 **와인이 밋밋해진다** | 토마토 파스타 ↔ 산조베제(키안티) |
| **③** | **탄닌은 단백질·지방이 잡는다** | 탄닌이 지방·단백질과 결합해 부드러워진다 | 스테이크 ↔ 카베르네 |
| **④** | **와인이 음식보다 달아야 한다** | 디저트가 와인보다 달면 와인이 시고 마르게 느껴진다 | 타르트 ↔ 소테른 |
| **⑤** | **짠맛은 산도·거품·단맛의 친구** | 짠맛이 산도를 부드럽게, 거품이 기름기를 씻어낸다 | 튀김 ↔ 샴페인 / 하몽 ↔ 피노 셰리 |

> **하나만 기억한다면 ①이다.** 섬세한 와인을 강한 음식과 붙이면 와인이 사라지고, 강한 와인을 섬세한 음식과 붙이면 음식이 사라진다.

## 2. 두 가지 방향

| 방향 | 설명 | 예 |
|---|---|---|
| **닮게 (조화)** | 비슷한 성질끼리 | 버터 소스 생선 ↔ 오크 샤르도네(둘 다 크리미) |
| **반대로 (대비)** | 상반된 성질로 균형 | 기름진 삼겹살 ↔ 산도 높은 화이트 · 매운 음식 ↔ 오프드라이 리슬링 |

**둘 다 옳다.** 어느 쪽을 택할지는 그날의 기분이다.

## 3. 지역이 맞으면 대개 맞는다

> **"What grows together goes together"** — 같은 땅에서 난 것끼리는 수백 년에 걸쳐 서로 맞춰졌다.

| 지역 | 음식 | 와인 |
|---|---|---|
| 토스카나 | 토마토·올리브유·페코리노 | **산조베제(키안티)** |
| 피에몬테 | 트러플·바냐 카우다·소고기 | **네비올로(바롤로)** |
| 갈리시아 | 문어·조개 | **알바리뇨** |
| 안달루시아 | 하몽·튀김·올리브 | **셰리(피노)** |
| 부르고뉴 | 뵈프 부르기뇽·에푸아스 | **피노 누아** |
| 알자스 | 슈크루트·타르트 플랑베 | **리슬링·피노 그리** |
| 안데스 | 구운 소고기(아사도) | **말벡** |

**처음 보는 요리를 만났을 때 가장 안전한 첫수**는 그 지역의 와인을 찾아보는 것이다.

## 4. 음식별 빠른 표

### 해산물·생선

| 음식 | 와인 |
|---|---|
| **굴·조개** | 뮈스카데 · **샤블리** · 알바리뇨 · **만사니야** |
| 회 (흰살) | 그뤼너 벨트리너 · 알바리뇨 · **드라이 리슬링** |
| 회 (참치·연어) | 로제 · 가벼운 피노 누아(**차게**) |
| 구운 생선 | 무오크 샤르도네 · 베르멘티노 |
| 버터·크림 소스 생선 | **오크 샤르도네** |
| 새우·게 | 샴페인 · 리슬링 |
| **튀김류** | **샴페인 · 카바 · 스파클링** (거품이 기름을 씻는다) |

### 고기

| 음식 | 와인 |
|---|---|
| **소 스테이크·구이** | **카베르네 · 보르도 · 말벡 · 시라** |
| 소 조림(장조림·찜) | 시라 · 리오하 · 브루넬로 |
| 돼지 (수육·보쌈) | **가벼운 레드(차게) · 리슬링 · 피노 그리** |
| **삼겹살·오겹살** | 산도 높은 레드(**보졸레·발폴리첼라**) 또는 **스파클링** |
| 양고기 | **보르도 · 리오하 · 시라** (허브 향이 잘 맞는다) |
| 닭 (구이) | **샤르도네 · 피노 누아** |
| 닭 (튀김) | **샴페인** · 드라이 로제 |
| 오리 | **피노 누아** · 아마로네 |
| 햄·소시지·샤퀴테리 | 보졸레 · **로제** · 랑그독 |

### 채소·기타

| 음식 | 와인 |
|---|---|
| 샐러드(비네그레트) | **소비뇽 블랑** (드레싱의 산을 받는다) |
| 버섯 요리 | **피노 누아** · 네비올로 |
| 토마토 소스 | **산조베제** · 바르베라 |
| 트러플 | **바롤로·바르바레스코** |
| 아스파라거스 | **소비뇽 블랑** (다른 와인은 대개 어긋난다) |

### 치즈 — 통설과 다르다

> **"치즈엔 레드"는 절반만 맞다.** 실제로는 **화이트가 더 잘 맞는 경우가 많다.**

| 치즈 | 와인 |
|---|---|
| 신선 치즈(모차렐라·염소) | **소비뇽 블랑** · 스파클링 |
| 세미하드(고다·그뤼예르) | 샤르도네 · 가벼운 레드 |
| **하드(파르미지아노·페코리노)** | **레드(산조베제·네비올로)** · 스파클링 |
| **블루(고르곤졸라·로크포르)** | **소테른 · 포트** (단맛이 짠맛·자극을 감싼다) |
| **워시드 린드(에푸아스·타레조)** | **게뷔르츠트라미너** · 부르고뉴 화이트 |
| 브리·카망베르 | **샴페인** |

### 디저트

| 음식 | 와인 |
|---|---|
| 과일 타르트 | **소테른 · 아이스바인 · 늦수확 리슬링** |
| **초콜릿** | **포트 · 바뉼스** (일반 레드는 대부분 실패한다) |
| 크림·커스터드 | 소테른 · 토카이 |
| 견과·캐러멜 | **마데이라 · 올로로소 셰리** |

## 5. 한식과 와인

한식은 **간장·고추장·마늘·참기름·발효**라는 강한 축이 있어 서양식 공식이 그대로 통하지 않는다. 실용적인 정리는 다음과 같다.

| 음식 | 와인 | 이유 |
|---|---|---|
| **불고기·갈비** | **말벡 · 시라 · 진판델 · 리오하** | 간장·설탕의 단맛에 **과일이 진한 레드**가 맞는다 |
| **삼겹살** | 보졸레·발폴리첼라(차게) · **카바** | 지방을 산도·거품으로 씻는다 |
| **삼계탕·백숙** | **오크 샤르도네** · 피노 그리 | 담백한 무게를 맞춘다 |
| **회·물회** | 그뤼너 벨트리너 · **알바리뇨** · 드라이 리슬링 | |
| **해물찜·아귀찜** | **오프드라이 리슬링** · 게뷔르츠트라미너 | 매운맛에 **약간의 단맛** |
| **김치찌개·부대찌개** | **오프드라이 리슬링** · 로제 · 람브루스코 | 신맛+매운맛+짠맛의 조합. 탄닌 있는 레드는 피한다 |
| **떡볶이** | 람브루스코 · **오프드라이 리슬링** | |
| **전·부침개** | **샴페인 · 카바** · 무오크 샤르도네 | 기름기 |
| **잡채** | 피노 누아 · **로제** | |
| **된장찌개** | 가벼운 레드 · **셰리 아몬티야도** | 감칠맛끼리 맞춘다 |
| **육회·생고기** | **피노 누아** · 가벼운 보르도 | |
| **양념치킨** | **오프드라이 리슬링** · 로제 스파클링 | |
| **한우 구이** | **카베르네 · 보르도 · 바롤로** | |

> **매운 음식의 핵심 규칙 두 가지**
> **① 알코올을 낮춘다.** 알코올이 캡사이신의 매운 느낌을 증폭시킨다. 15%짜리 진판델을 매운 음식과 먹으면 입이 타들어간다.
> **② 약간의 단맛을 준다.** 잔당이 매운맛을 눌러준다.
> 그래서 **독일·알자스의 오프드라이 리슬링(8~11%)**이 한식 매운 음식의 거의 만능 해답이다.

## 6. 지뢰 — 실패하는 조합

| 조합 | 무슨 일이 일어나나 |
|---|---|
| **탄닌 강한 레드 + 매운 음식** | 매운맛이 배가되고 탄닌이 쓰게 느껴진다. **가장 흔한 실패** |
| **탄닌 강한 레드 + 생선(특히 등푸른)** | **비린 금속 맛**이 난다. 와인의 철분과 생선 기름이 반응한다 |
| **레드 + 초콜릿** | 대부분 어긋난다. 초콜릿의 쓴맛과 탄닌이 충돌 |
| **드라이 와인 + 디저트** | 와인이 시고 마르게 느껴진다 |
| 오크 강한 화이트 + 섬세한 회 | 오크가 생선을 덮는다 |
| **아티초크·아스파라거스 + 대부분의 와인** | 특유의 성분이 와인을 금속 맛으로 바꾼다 |
| **식초 강한 드레싱 + 저산도 와인** | 와인이 밍밍해진다 |
| **계란 요리 + 탄닌** | 유황·질감이 어긋난다 |

## 7. 곤란할 때의 만능패

| 상황 | 답 |
|---|---|
| **음식이 여럿이고 뭘 낼지 모르겠다** | **샴페인 또는 드라이 스파클링.** 거의 모든 음식과 맞는다 |
| 사람이 많고 취향이 갈린다 | **드라이 로제** · 가벼운 피노 누아 |
| 한식 상차림 전체 | **오프드라이 리슬링** 또는 **카바** |
| 튀김·기름진 것 위주 | **스파클링** |
| 매운 것 위주 | **오프드라이 리슬링**(알코올 낮은 것) |
| 고기 위주 | 리오하 크리안사 · 말벡 (무난하고 저렴하다) |

> **결국 가장 중요한 것** — 좋아하는 와인을 좋아하는 음식과 먹는 것이 어긋난 "정답 페어링"보다 낫다. 페어링은 **실패를 줄이는 도구**이지 즐거움의 조건이 아니다.
