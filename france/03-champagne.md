# 샹파뉴 Champagne

> 프랑스 최북단 산지. **밭이 아니라 "마을(크뤼)"에 등급을 매기는** 독특한 체계.

![샹파뉴 하위 지구 지도](../assets/champagne.svg)

## 1. 기본 구조

| 항목 | 내용 |
|---|---|
| 주품종 | **샤르도네** · **피노 누아** · **피노 뫼니에** (+ 아르반, 프티 메슬리에 등 4종 소량) |
| 양조 | **전통방식(Méthode traditionnelle)** — 병내 2차 발효 |
| 최소 숙성 | 논빈티지 15개월(효모접촉 12개월) / **빈티지 36개월** |
| 등급 단위 | **마을 단위** — 에셸 데 크뤼(Échelle des Crus) 100점 척도의 잔재 |

## 2. 마을 등급 (Échelle des Crus)

| 등급 | 마을 수 | 기준 |
|---|---|---|
| **그랑 크뤼 Grand Cru** | **17** | 100% |
| **프리미에 크뤼 Premier Cru** | **42** | 90~99% |
| 그 외 | 약 260 | 80~89% |

### 그랑 크뤼 17개 마을

| 지구 | 마을 | 주품종 |
|---|---|---|
| **몽타뉴드랭스** | **Verzenay**, **Verzy**, **Mailly-Champagne**, **Bouzy**, **Ambonnay**, Louvois, Beaumont-sur-Vesle, Puisieulx, Sillery | 피노 누아 |
| **발레드라마른** | **Aÿ**, Tours-sur-Marne | 피노 누아 |
| **코트데블랑** | **Le Mesnil-sur-Oger**, **Avize**, **Cramant**, **Oger**, Chouilly, Oiry | 샤르도네 |

> 표기 규칙: 그랑크뤼 표기는 **사용한 포도가 100% 그랑크뤼 마을 것일 때만** 가능하다.

## 3. 5개 하위 지구

| 지구 | 주품종 | 성격 | 핵심 마을 |
|---|---|---|---|
| **몽타뉴드랭스 Montagne de Reims** | 피노 누아 | 구조·힘·붉은 과실 | Verzenay, Ambonnay, Bouzy, Mailly |
| **발레드라마른 Vallée de la Marne** | 피노 뫼니에 | 과실 풍부, 조기 접근성 | Aÿ(피노 누아), Hautvillers, Cumières |
| **코트데블랑 Côte des Blancs** | 샤르도네 | 미네랄·긴장감·장기 숙성 | Le Mesnil-sur-Oger, Avize, Cramant, Vertus(1er) |
| **코트드세잔 Côte de Sézanne** | 샤르도네 | 더 따뜻하고 풍만 | Sézanne, Vindey |
| **코트데바르 Côte des Bar (오브)** | 피노 누아 | 남쪽 100km, 샤블리와 같은 키메리지안 토양 | Les Riceys, Celles-sur-Ource |

## 4. 스타일 분류

| 표기 | 의미 |
|---|---|
| **Blanc de Blancs** | 화이트 품종(샤르도네)만 |
| **Blanc de Noirs** | 흑포도(피노 누아/뫼니에)만 |
| **Rosé d'assemblage** | 레드 와인을 소량 블렌딩 (샹파뉴만 허용) |
| **Rosé de saignée** | 침용 후 색을 뽑아냄. 더 진하고 구조적 |
| **NV / MV** | 논빈티지 — 하우스 스타일의 기준 |
| **Millésime** | 단일 빈티지 |
| **Prestige Cuvée** | 최상위 라인 (Dom Pérignon, Cristal, Comtes de Champagne 등) |

### 도자주(당도) 등급

| 표기 | 잔당 (g/L) |
|---|---|
| Brut Nature / Zéro Dosage | 0~3 (첨가 없음) |
| Extra Brut | 0~6 |
| **Brut** | 0~12 (가장 일반적) |
| Extra Dry | 12~17 |
| Sec | 17~32 |
| Demi-Sec | 32~50 |
| Doux | 50 이상 |
