# 부르고뉴 Bourgogne

> 보르도가 "샤토(생산자)"에 등급을 주는 반면, 부르고뉴는 **밭(클리마 climat)에 등급을 준다.** 그래서 같은 밭을 여러 생산자가 나눠 갖는다.

## 1. 등급 피라미드

| 등급 | 비율 | 표기 방식 | 예시 |
|---|---|---|---|
| **그랑 크뤼 Grand Cru** | 약 1% | **밭 이름만** 표기 (마을명 없음) | `Chambertin 샹베르탱`, `Montrachet 몽라셰`, `Corton 코르통` |
| **프리미에 크뤼 Premier Cru (1er)** | 약 10% | 마을명 + 밭 이름 | `Gevrey-Chambertin 1er Cru Clos St-Jacques 주브레샹베르탱 프리미에 크뤼 클로 생자크` |
| **빌라주 Village** | 약 37% | 마을명만 | `Volnay 볼네`, `Meursault 뫼르소` |
| **레지오날 Régionale** | 약 52% | 광역명 | `Bourgogne Rouge 부르고뉴 루주`, `Bourgogne Aligoté 부르고뉴 알리고테` |

**핵심 규칙**: 라벨에 마을명이 없고 밭 이름만 있으면 그랑 크뤼다. `Chambertin 샹베르탱`은 그랑 크뤼, `Gevrey-Chambertin 주브레샹베르탱`은 마을 등급.

> 마을들이 19세기에 유명한 그랑크뤼 이름을 자기 마을명에 붙였다(Gevrey 주브레 → Gevrey-**Chambertin** 주브레샹베르탱, Puligny 퓔리니 → Puligny-**Montrachet** 퓔리니몽라셰). 이 때문에 헷갈리기 쉽다.

## 2. 지리 — 사면의 어디에 있는가

| 구분 | 내용 |
|---|---|
| 지형 | 남북으로 길게 이어지는 동향(東向)·남동향 석회암 사면 |
| 최적 위치 | 사면 **중턱** — 배수 좋고 표토 얇음 → 그랑 크뤼가 집중 |
| 사면 상부 | 토양 척박·서늘 → 프리미에 크뤼 또는 오트코트 |
| 사면 하부/평지 | 충적토 깊음 → 빌라주·레지오날 |

## 3. 품종 Cépages 세파주

> 부르고뉴는 **단 두 품종**으로 세계에서 가장 세분화된 밭 등급을 만들었다. 품종이 하나뿐이니 **차이는 전부 밭에서 온다** — 이것이 클리마 체계가 성립하는 전제다.

| 품종 | 색 | 비중 | 역할 |
|---|---|---|---|
| **Pinot Noir 피노 누아** | 레드 | 레드의 사실상 전부 | 코트도르 레드 전 등급 |
| **Chardonnay 샤르도네** | 화이트 | 화이트의 약 90% | 샤블리 ~ 몽라셰 ~ 마코네 |
| **Aligoté 알리고테** | 화이트 | 약 6% | 부즈롱 · 부르고뉴 알리고테 |
| **Gamay 가메** | 레드 | 보졸레 | 보졸레 · 부르고뉴 파스투그랭 |
| **Pinot Beurot 피노 뵈로 · Pinot Blanc 피노 블랑 · Sacy 사시 · César 세자르 · Melon 믈롱** | | 극소량 | 잔존 토착 품종 |

### Pinot Noir 피노 누아 — 밭을 비추는 거울

| 항목 | 내용 |
|---|---|
| 향 | **체리·라즈베리·딸기**, 장미·제비꽃. 숙성하면 **버섯·낙엽·수렵육·트러플** |
| 구조 | **색 옅음 · 탄닌 낮음~중간 · 산도 높음.** 진하지 않으면서 오래 간다 |
| 재배 | **극도로 까다롭다** — 껍질이 얇아 곰팡이·부패에 약하고, 일찍 싹이 터 봄 서리를 맞는다. 수확량이 조금만 늘어도 급격히 묽어진다 |
| 유전 | **유전적으로 매우 불안정**해 돌연변이가 잦다. **Pinot Gris 피노 그리 · Pinot Blanc 피노 블랑 · Pinot Meunier 피노 뫼니에**가 모두 피노 누아의 변이체다 |
| 특성 | **토양의 차이를 가장 정직하게 드러낸다.** 밭 몇 백 미터 차이가 잔에서 감지되는 이유이자, 부르고뉴가 클리마 체계를 갖게 된 이유 |

> **클론 vs 마살 셀렉션** — 1970~80년대 수확량과 병 저항성을 높인 **클론(clone)**이 대량 보급되면서 부르고뉴 와인이 획일화됐다는 비판이 나왔다. 이에 대한 반동으로, 오래된 밭에서 우수한 나무를 골라 접붙이는 **마살 셀렉션(sélection massale 셀렉시옹 마살)**이 다시 늘고 있다. 유전적 다양성이 복합성을 만든다는 논리다.

### Chardonnay 샤르도네 — 그릇이 되는 품종

1999년 DNA 분석으로 **Pinot 피노 × Gouais Blanc 구애 블랑**의 자연 교배임이 밝혀졌다. 구애 블랑은 중세에 널리 심겼다가 지금은 사라진 평범한 품종이다.

| 항목 | 내용 |
|---|---|
| 향 | **품종 자체의 향이 옅다** — 그래서 토양·양조·오크를 그대로 담는다 |
| 서늘한 곳 | 감귤·풋사과·부싯돌 (샤블리) |
| 중간 | 흰꽃·헤이즐넛·버터 (코트드본) |
| 따뜻한 곳 | 복숭아·멜론·꿀 (마코네) |
| 구조 | 산도 중간~높음. 껍질이 얇아 산화에 주의가 필요 |
| 재배 | 피노보다 훨씬 튼튼하고 어디서나 자란다. **세계에서 가장 널리 심긴 백포도**가 된 이유 |

> **양조가 품종보다 크게 작용한다** — 젖산발효(malolactique 말로락티크)를 시키면 버터 향이, 앙금 저어주기(bâtonnage 바토나주)를 하면 질감이, 새 오크를 쓰면 바닐라·토스트가 붙는다. "샤르도네 맛"이라 불리는 것의 상당 부분은 사실 양조의 맛이다.

### Aligoté 알리고테 — 재평가 중인 조연

| 항목 | 내용 |
|---|---|
| 향 | 레몬·풋사과·흰꽃, 쌉쌀한 뒷맛 |
| 구조 | **산도가 매우 높고 알코올이 낮다** |
| 위상 | 오랫동안 카시스 리큐어를 섞는 **키르(Kir 키르)**용 취급을 받았다 |
| 반전 | **Bouzeron 부즈롱**은 부르고뉴 유일의 알리고테 단독 AOC이고, 코트드뉘의 노목 알리고테(Ponsot 퐁소의 Monts Luisants Blanc, Coche-Dury 코슈 뒤리)는 최고가에 거래된다 |
| 지금 | 온난화로 산도가 무기가 되면서 **Les Aligoteurs 레 잘리고퇴르** 같은 생산자 모임이 생길 만큼 재평가 |

### Gamay 가메 — 추방당한 품종

| 항목 | 내용 |
|---|---|
| 유전 | 샤르도네와 마찬가지로 **Pinot × Gouais Blanc** 교배 — 피노의 형제 |
| 향 | 붉은 과실·바나나·제비꽃. 탄닌 낮고 산도 높음 |
| 1395년 | 부르고뉴 공작 **필리프 르 아르디(Philippe le Hardi)**가 가메를 "매우 나쁘고 불충한 품종"이라며 코트도르에서 **추방**했다. 수확량이 많고 일찍 익어 피노를 밀어냈기 때문이다 |
| 결과 | 가메는 남쪽 화강암 지대(보졸레)로 밀려났고, 코트도르는 피노 단일 산지가 되었다 |
| 잔존 | **Bourgogne Passetoutgrain 부르고뉴 파스투그랭** — 가메 최소 30% + 피노 누아를 섞는 옛 방식의 흔적 |

### 잔존 토착 품종

| 품종 | 위치 | 비고 |
|---|---|---|
| **Pinot Beurot 피노 뵈로** | 코트도르 극소량 | = 피노 그리. 옛 밭에 섞여 남아 있다 |
| **Pinot Blanc 피노 블랑** | 극소량 | 화이트 부조 등 |
| **Sacy 사시** | 오세루아 | 크레망 드 부르고뉴용 |
| **César 세자르** | Irancy 이랑시 | 로마 시대 유래설. 색·탄닌 보강용 소량 |
| **Melon 믈롱** | 사실상 소멸 | 루아르로 옮겨가 **뮈스카데**가 되었다 |

### 등급별 품종 규정

| 등급 | 레드 | 화이트 |
|---|---|---|
| **Grand Cru 그랑 크뤼 · Premier Cru 프리미에 크뤼 · Village 빌라주** | **피노 누아 100%** (극소수 예외) | **샤르도네 100%** |
| **Bourgogne 부르고뉴** | 피노 누아 (가메 일부 허용 구역 있음) | 샤르도네 |
| **Bourgogne Aligoté 부르고뉴 알리고테** | – | 알리고테 100% |
| **Bouzeron 부즈롱** | – | **알리고테 100%** (단독 AOC) |
| **Bourgogne Passetoutgrain** | 가메 30~70% + 피노 누아 | – |
| **Crémant de Bourgogne 크레망 드 부르고뉴** | 피노 누아·가메 | 샤르도네·알리고테·사시·믈롱 |
| **Beaujolais 보졸레** | **가메 100%** | (샤르도네 소량) |

## 7. 도멘 vs 네고시앙

| 구분 | 의미 | 대표 |
|---|---|---|
| **Domaine** | 자기 밭에서 재배·양조 | DRC, Leroy 르루아, Armand Rousseau 아르망 루소, Coche-Dury 코슈 뒤리 |
| **Maison / Négociant** | 포도·와인을 사서 양조·숙성 | Louis Jadot 루이 자도, Joseph Drouhin 조제프 드루앵, Bouchard Père & Fils 부샤르 페르 에 피스, Faiveley 페블레 |
| **Micro-négoce 미크로 네고스** | 소규모 신흥 네고시앙 | Lucien Le Moine 뤼시앵 르 무안, Benjamin Leroux 뱅자맹 르루, Maison Chanzy 메종 샹지 |

> 최근에는 네고시앙도 자기 밭을 많이 보유하고, 유명 도멘도 네고시앙 부문을 운영해(예: Domaine Leflaive 도멘 르플레브 → Leflaive & Associés 르플레브 에 아소시에) 경계가 흐려졌다.
