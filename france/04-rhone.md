# 론 밸리 Vallée du Rhône

> 북부와 남부는 사실상 다른 산지다. 북부는 **시라 단일 품종**의 급경사 사면, 남부는 **그르나슈 중심 블렌드**의 넓은 자갈 평원.

![론 밸리 지도](../assets/rhone.svg)

| 구분 | 북부 Rhône Septentrional 론 셉탕트리오날 | 남부 Rhône Méridional 론 메리디오날 |
|---|---|---|
| 면적 | 전체의 약 5% | 약 95% |
| 기후 | 대륙성 (한랭) | 지중해성 (건조·고온) |
| 레드 품종 | **시라 100%** (비오니에 소량 혼합 허용) | **그르나슈** + 무르베드르 + 시라 (GSM) |
| 화이트 품종 | 비오니에 / 마르산 · 루산 | 그르나슈 블랑, 클레레트, 부르불랑, 루산 |
| 지형 | 화강암 급경사 계단식 사면 | 갈레 룰레(둥근 자갈) 평원 |
| 바람 | 미스트랄 | 미스트랄 |
| 크뤼 수 | **8개** | **10개** |

> **론의 크뤼는 총 18개** — 북부 8개 + 남부 10개. 2024년 9월 로덩(Laudun 로덩)이 9년 만에 새로 승격해 18번째가 되었다.
> 품종별 특징은 [아래 품종 절](#품종-cépages-세파주) 참고.
> 크뤼 아래로 **Côtes du Rhône Villages 코트 뒤 론 빌라주(마을명 표기)** → **Côtes du Rhône Villages 코트 뒤 론 빌라주** → **Côtes du Rhône 코트 뒤 론** 순의 피라미드.

# 품종 Cépages 세파주

## 레드 품종

### Syrah 시라 — 북부의 유일한 레드

1998년 DNA 분석으로 **Dureza 뒤레자 × Mondeuse Blanche 몽되즈 블랑슈**의 자연 교배임이 밝혀졌다. 두 품종 모두 론·사부아 일대에 자생하므로 **시라는 론 북부 토착 품종**이다(시라즈·페르시아 기원설은 근거 없는 전설).

| 항목 | 내용 |
|---|---|
| 향 | **후추**(로툰돈 rotundone), 제비꽃, 블랙올리브, 블랙베리, 훈연·베이컨, 감초 |
| 구조 | 색 진함 · 탄닌 중~강 · 산도 중간 · 알코올 중~높음 |
| 숙성 | 20~40년. 어릴 때 닫혀 있다가 10년 전후에 열린다 |
| 기후 반응 | **서늘하면 후추·꽃·올리브 / 더우면 잼·감초·초콜릿** — 같은 품종이 북부와 남부에서 딴판인 이유 |

**북부 안에서도 갈린다**

| AOC | 토양 | 시라의 얼굴 |
|---|---|---|
| Côte-Rôtie 코트로티 | 편암·편마암 | 가장 향기롭고 우아. 비오니에 공동 발효로 화사함 |
| Hermitage 에르미타주 | 화강암 | 가장 웅장·구조적. 장수의 기준점 |
| Cornas 코르나스 | 화강암 | 가장 야성적·거침. 젊을 때 닫힘 |
| Crozes-Hermitage 크로즈에르미타주 | 자갈·충적토 | 가볍고 과실 중심, 조기 음용 |
| Saint-Joseph 생조제프 | 화강암 | 중간. 북쪽 구간이 최상 |

> **줄기 사용(vendange entière 방당주 앙티에르)**: 북부 론은 전통적으로 포도송이를 줄기째 넣는다. 향신료·긴장감을 더하지만 덜 익은 줄기는 풋내를 낸다. Jamet 자메·Clape 클라프는 전통적으로 전량 사용, Guigal 기갈은 제경(除梗) 쪽이다.

### Grenache Noir 그르나슈 누아 — 남부의 몸통

스페인 아라곤 원산(**Garnacha 가르나차**). 남부 론 최대 재배 품종이며 샤토뇌프뒤파프 블렌드의 중심.

| 항목 | 내용 |
|---|---|
| 향 | 딸기·라즈베리·말린 자두, **가리그(garrigue 가리그 — 타임·로즈메리·라벤더 등 지중해 관목 향)**, 후추·감초 |
| 구조 | **색 옅음 · 탄닌 낮음 · 산도 낮음 · 알코올 매우 높음(15~16%)** |
| 약점 | **산화에 취약**. 새 오크·작은 배럴과 상성이 나쁘다 |
| 양조 | 큰 나무통(foudre 푸드르)·콘크리트 탱크·유리 섬유 탱크에서 숙성해 산소 접촉을 줄인다 |
| 노목 | 수령이 곧 품질. 오래된 나무는 수확량이 떨어지면서 응축도와 균형이 급격히 좋아진다 |

> **Château Rayas 샤토 라야스**가 증명한 것 — 모래 토양의 서늘한 구획에서 그르나슈 100%로 만들면 부르고뉴 피노 누아 같은 섬세함이 나온다. "그르나슈는 진하기만 하다"는 통념의 반례.

### Mourvèdre 무르베드르 — 뼈대와 수명

스페인 원산(**Monastrell 모나스트렐**). **가장 늦게 익어** 아주 덥고 긴 계절이 필요하며, 온난화로 남부 론에서 재배 면적이 늘고 있다.

| 항목 | 내용 |
|---|---|
| 향 | 가죽·야생고기·흙·후추, 검은 과실. 숙성하면 트러플·수렵육 |
| 구조 | 색 진함 · **탄닌 강함** · 산도 양호 |
| 핵심 | **환원적**이라 그르나슈의 산화를 막아준다 → 블렌드의 수명을 늘리는 장치 |
| 대표 | **Château de Beaucastel 샤토 드 보카스텔**(무르베드르 비율 30% 이상) · Bandol 방돌(프로방스, 50% 이상 의무) |

### Cinsault 생소 — 신선함과 로제

| 항목 | 내용 |
|---|---|
| 향 | 신선한 붉은 과실, 장미, 사탕 |
| 구조 | 색 옅음 · 탄닌 낮음 · **알코올 낮음** |
| 강점 | 더위·건조에 강하고 수확량이 많다. 블렌드에 신선함과 향을 넣으면서 알코올을 낮춘다 |
| 대표 | **Tavel 타벨** 로제의 핵심. 남부 레드에도 소량 |

### Carignan 카리냥 · Counoise 쿠누아즈 · 그 밖의 소수 품종

| 품종 | 성격 | 비고 |
|---|---|---|
| **Carignan 카리냥** | 산도·탄닌 높고 색 진함 | 노목이 아니면 거칠다. **샤토뇌프뒤파프에는 불허**, 광역 Côtes du Rhône 코트 뒤 론·랑그독에서 사용 |
| **Counoise 쿠누아즈** | 후추·붉은 과실, **산도 높고 알코올 낮음** | 그르나슈의 무거움을 눌러준다. Beaucastel 보카스텔이 적극 사용 |
| **Vaccarèse 바카레즈** (Brun Argenté 브룅 아르장테) | 가볍고 향기, 산도 유지 | 샤토뇌프 13품종 |
| **Muscardin 뮈스카르댕** | 색 옅고 향기로움 | 샤토뇌프 13품종 |
| **Terret Noir 테레 누아** | 산도 높고 늦게 익음 | 샤토뇌프 13품종 |
| **Picpoul Noir 픽풀 누아** | 매우 높은 산도 | 샤토뇌프 13품종 |

## 화이트 품종

### Viognier 비오니에 — 콩드리외의 단일 품종

1960년대에 **전 세계 재배 면적이 8 ha까지 줄어** 멸종 직전이었다. Georges Vernay 조르주 베르네를 비롯한 소수가 지켜냈고, 1980년대 이후 세계적으로 퍼졌다.

| 항목 | 내용 |
|---|---|
| 향 | **살구·복숭아·인동꽃·머스크**, 흰 꽃 |
| 구조 | **산도 낮음 · 알코올 높음 · 오일리(glycerol)한 질감** |
| 난점 | **수확 타이밍이 극도로 좁다** — 이르면 향이 없고, 늦으면 산도가 무너지고 무거워진다 |
| 숙성 | 대개 3~5년 안에 마신다. 예외적으로 Château-Grillet 샤토그리예는 장기 숙성형 |

> **코트로티의 공동 발효(co-fermentation)** — 시라에 비오니에를 **최대 20%까지** 함께 발효할 수 있다(실제로는 보통 5% 이하). 비오니에가 시라의 색소를 안정시켜 **색이 더 진해지고**, 동시에 꽃향이 올라간다. 화이트를 섞어 레드가 더 진해지는 역설.

### Marsanne 마르산 · Roussanne 루산 — 북부 화이트의 짝

둘은 거의 항상 함께 쓰이며 서로의 결점을 메운다.

| | **Marsanne 마르산** | **Roussanne 루산** |
|---|---|---|
| 향 | 아몬드·마르멜로·밀랍·배 | 허브차·백도·꿀·꽃 |
| 구조 | **풍만·묵직, 산도 낮음** | **산도 높고 향기로움, 더 가벼움** |
| 역할 | 살집(뼈에 붙은 살) | 뼈대와 향 |
| 재배 | 안정적, 수확량 많음 | **까다롭다** — 병충해에 약하고 결실이 불규칙 |
| 숙성 | 어릴 때 무겁다가 **8~15년 뒤 견과·꿀로 만개** | |

> **에르미타주 블랑**은 마르산 중심으로, 좋은 해에는 30년 이상 간다. 어릴 때 닫혀 있다가 중간에 한동안 침묵하는(dumb phase) 구간이 있는 것으로 유명하다.
> **Château de Beaucastel 샤토 드 보카스텔 Roussanne Vieilles Vignes 루산 비에유 비뉴**는 남부에서 루산 단일로 만든 예외적 명품.

### 남부 화이트 품종

| 품종 | 성격 | 쓰임 |
|---|---|---|
| **Grenache Blanc 그르나슈 블랑** | 풍만·낮은 산도, 흰 꽃·펜넬·아니스 | 남부 화이트 블렌드의 주력 |

## GSM 블렌딩의 논리

남부 론 블렌드는 취향이 아니라 **기능 분담**이다. 각 품종이 다른 품종의 결점을 메운다.

| 품종 | 넣는 이유 | 없으면 생기는 문제 |
|---|---|---|
| **G** Grenache 그르나슈 | 알코올·과실·풍만한 질감 = **몸통** | 와인이 마르고 빈약해진다 |
| **S** Syrah 시라 | 색·후추·탄닌 구조 = **향과 뼈대** | 색이 옅고 향이 단조로워진다 |
| **M** Mourvèdre 무르베드르 | 강한 탄닌·환원력 = **골격과 수명** | 조기 산화되어 5년을 못 간다 |
| **+** Cinsault 생소 | 신선함·향, 알코올 희석 | 지나치게 무겁고 뜨거워진다 |
| **+** Counoise 쿠누아즈 | 산도·후추 | 산도가 낮아 늘어진다 |

> **온난화의 영향**: 그르나슈가 너무 쉽게 익어 알코올이 16%에 육박하면서, 최근 생산자들은 **무르베드르·생소·쿠누아즈 비율을 늘리고** 그르나슈를 서늘한 북향 구획으로 옮기는 추세다.
