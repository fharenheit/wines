# 스페인 와인 개요

![스페인 와인 산지 지도](../assets/spain-overview.svg)

> **포도밭 면적 세계 1위**(약 92만 ha)인데 생산량은 3위다. 건조하고 척박한 땅에 포도나무를 넓게 띄워 심어 단위 면적당 수확량이 낮기 때문이다.

## 1. 등급(원산지 명칭) 체계

EU 체계에 맞춰 **DOP(원산지보호명칭)** 과 **IGP(지리적표시보호)** 로 나뉜다. 스페인은 DOP 안에서 다시 4단계로 갈린다.

| 등급 | 원어 | 개수 | 내용 |
|---|---|---|---|
| **DOCa / DOQ** | Denominación de Origen 데노미나시온 데 오리헨 Calificada / Qualificada 데노미나시온 데 오리헨 칼리피카다 | **2** | 최상위. **Rioja 리오하**(1991) · **Priorat 프리오라트**(2000, 카탈루냐어로 DOQ) |
| **DO** | Denominación de Origen 데노미나시온 데 오리헨 | 약 70 | 프랑스 AOC에 해당하는 주력 등급 |
| **VP** | Vino de Pago 비노 데 파고 | 약 25 | **단일 포도밭(단일 에스타테) 명칭**. 이름만 보면 최상위 같지만 별개 트랙이다 |
| **VC** | Vino de Calidad 비노 데 칼리다드 con Indicación Geográfica 비노 데 칼리다드 | 소수 | DO 승격 대기 단계 |
| **VT / IGP** | Vino de la Tierra 비노 데 라 티에라 | 약 40 | 프랑스 IGP. 품종·양조가 자유로워 **명작이 자주 나온다** |
| **Vino** | | | 산지 표기 없음 |

> **비노 데 파고(VP)의 함정**: 등급표에서 가장 위에 놓이지만 **품질 서열이 아니라 "단일 에스타테" 인증**이다. DO에 속하지 않은 개별 와이너리가 자기 밭으로 독립 명칭을 받은 것이라, VP라고 해서 리오하 그란 레세르바보다 낫다는 뜻이 전혀 아니다.
>
> **VT의 역설**: DO 규정이 금지한 품종·수확량·양조법을 쓰려고 **일부러 등급을 내려** 출시하는 최상급 와인이 많다. Ossian 오시안(루에다 밖 노목 베르데호), Dominio de Valdepusa 도미니오 데 발데푸사, 그레도스 산악의 여러 가르나차가 그렇다.

## 2. 숙성 등급 — 스페인 라벨의 핵심

프랑스는 **밭**에, 이탈리아는 **산지**에 등급을 매기지만, **스페인은 "얼마나 오래 숙성했는가"에 등급을 매긴다.** 이것이 스페인 라벨을 읽는 첫 번째 열쇠다.

| 등급 | 원어 | 레드 | 화이트·로제 |
|---|---|---|---|
| **호벤 / 시노 크리안사** | Joven 호벤 / Sin Crianza 신 크리안사 | 숙성 규정 없음 | 규정 없음 |
| **로블레** | Roble 로블레 | 오크 3~6개월 (DO 규정 밖의 관행 표기) | – |
| **크리안사** | Crianza 크리안사 | **총 24개월** (오크 6개월 이상) | 총 18개월 (오크 6개월) |
| **레세르바** | Reserva 레세르바 | **총 36개월** (오크 12개월 이상) | 총 24개월 (오크 6개월) |
| **그란 레세르바** | Gran Reserva 그란 레세르바 | **총 60개월** (오크 18개월 이상) | 총 48개월 (오크 6개월) |

> **주의 1 — 지역마다 기준이 다르다.** 위는 일반 기준이고, **리오하는 더 엄격하다**(크리안사 오크 12개월, 레세르바 오크 12개월 + 병 6개월, 그란 레세르바 오크 24개월 + 병 24개월).
>
> **주의 2 — 숙성 등급 ≠ 품질 등급.** Vega Sicilia 베가 시실리아·Pingus 핑구스·L'Ermita 레르미타 같은 스페인 최고가 와인 중에는 라벨에 크리안사·레세르바를 아예 쓰지 않는 것이 많다. 최근 고급 생산자일수록 **숙성 등급 표기를 버리고 밭 이름을 쓰는** 추세다.

### 그래서 최근 스페인은 "밭"으로 옮겨가는 중이다

| 지역 | 새 체계 | 도입 |
|---|---|---|
| **Rioja 리오하** | Vino de Zona 비노 데 소나 → Vino de Municipio 비노 데 무니시피오 → **Viñedo Singular 비녜도 싱굴라르** | 2017 (2019 첫 출시) |
| **Priorat 프리오라트** | Vi de Vila 비 데 빌라 → Vi de Paratge 비 데 파라체 → Vinya Classificada 비냐 클라시피카다 → Gran Vinya Classificada 비냐 클라시피카다 | 2019 |
| **Bierzo 비에르소** | Vino de Villa 비노 데 비야 → Vino de Paraje 비노 데 파라헤 → Vino de Viña Clasificada 비냐 클라시피카다 비노 데 비냐 클라시피카다 | 2019 |
| **Cava 카바** | Cava de Guarda 카바 데 구아르다 → Cava de Guarda 카바 데 구아르다 Superior 구아르다 수페리오르 (Reserva · Gran Reserva · **Paraje Calificado 파라헤 칼리피카도**) | 2022 |

> 세 지역 모두 **부르고뉴식 피라미드**(광역 → 마을 → 단일 밭)를 도입했다. 스페인 와인 이해의 축이 "숙성 기간"에서 "밭"으로 옮겨가는 중이라는 신호다.

## 4. 스페인어 라벨 읽기 규칙

| 철자 | 소리 | 예 |
|---|---|---|
| **j** | **ㅎ** (목에서 긁는) | Jerez 헤레스 / Rioja 리오하 / Jumilla 후미야 |
| **g** + e, i | **ㅎ** | Gijón 히혼 / Requena 레케나는 예외(ㄱ) |
| **g** + a, o, u | ㄱ | Garnacha 가르나차 |
| **gue, gui** | 게, 기 (u는 묵음) | Guitián 기티안 |
| **ll** | **ㅇ + 이** | Jumilla 후미야 / Mallorca 마요르카 / Castilla 카스티야 |
| **ñ** | 니 | Albariño 알바리뇨 / Viñedo 비녜도 |
| **h** | **항상 묵음** | Haro 아로 / Hondarrabi 온다라비 |
| **v** | **ㅂ** (b와 같은 소리) | Verdejo 베르데호 |
| **z, ce, ci** | 스페인 본토에서는 **θ**(영어 th), 표기는 ㅅ | Zamora 사모라 / Cencibel 센시벨 |
| **qu** | ㄲ/ㅋ (u 묵음) | Quirós 키로스 |
| **rr** | 굴리는 ㄹ | Sierra 시에라 |
| **x** (카탈루냐어) | **슈** | Xarel 사렐·lo 사렐로 / Xerès |
| 강세 부호 | 그 음절을 세게 | Málaga 말라가 / Príncipe |

> **카탈루냐어는 다르다.** 프리오라트·페네데스의 라벨은 스페인어가 아니라 카탈루냐어인 경우가 많다. `Vi` = 와인(Vino), `Vinya` = 포도밭(Viña), `Celler` = 와이너리(Bodega), `Clos` = 담으로 둘러싼 밭.

## 6. 스페인 와인의 흐름 (간략사)

| 시기 | 사건 |
|---|---|
| 1863~1880년대 | **프랑스 필록세라** → 보르도 상인들이 리오하로 대거 이주. **바리카(225 L 오크통) 숙성이 이때 리오하에 정착** |
| 1890년대~ | 스페인에도 필록세라 도달. 다만 **카나리아 제도는 끝내 피해를 입지 않아** 지금도 자근(自根) 노목이 남아 있다 |
| 1936~1975 | 내전과 프랑코 시대. 협동조합 중심 대량생산, 품질 정체 |
| 1970~80년대 | **Vega Sicilia 베가 시실리아**의 국제적 명성, **Torres 토레스**의 현대화, **리베라 델 두에로 DO 승격(1982)** |
| 1989~1990년대 | **프리오라트 부활** — 다섯 명이 버려진 편암 산지에 들어가 Clos 시리즈를 만든다. **Pingus 핑구스(1995)** 등장 |
| 2000년대 | 과잉 추출·신오크 스타일이 정점을 찍고 반작용 시작 |
| 2010년대~ | **밭 중심 회귀** — 리오하·프리오라트·비에르소의 밭 등급 도입, 그레도스·카나리아·리베이라 사크라 등 **서늘한 고지대·화산 산지의 재발견**, 셰리 재평가 |
