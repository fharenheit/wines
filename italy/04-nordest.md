# 트렌티노알토아디제 · 프리울리베네치아줄리아

> 알프스와 슬로베니아 국경에 걸친 산지. **이탈리아 화이트 와인의 최고 수준**이 여기 있다.

![북동부 지도](../assets/nordest.svg)

# 1. 알토아디제 Alto Adige (쥐트티롤 Südtirol)

1919년까지 오스트리아 영토. 지금도 **독일어가 공용어**이고 와인 이름도 이탈리아어·독일어를 병기한다.

| 항목 | 내용 |
|---|---|
| 위치 | 이탈리아 최북단. 아디제 강 계곡 |
| 면적 | 약 5,600 ha (매우 작다) |
| 특징 | 이탈리아에서 **DOC 비율이 가장 높다(98%)** |
| 기후 | 알프스 한랭 + 지중해 남풍(Ora)의 교차 → 큰 일교차 |
| 고도 | 200~1,000 m |

## 1-1. 품종

| 색 | 품종 |
|---|---|
| **화이트 (65%)** | **피노 비앙코(Weissburgunder)**, **게뷔르츠트라미너**, 소비뇽, 샤르도네, 피노 그리조, **케르너**, 실바너, 리슬링, 뮐러 투르가우 |
| **레드 (35%)** | **스키아바(Vernatsch)** — 가볍고 일상적 / **라그레인 Lagrein** — 짙고 구조적 / **피노 네로** |

> **게뷔르츠트라미너의 원산지**로 여겨지는 마을 **트라민(Tramin / Termeno)**이 여기 있다.

## 1-2. 하위 구역 (Sottozone)

| 구역 | 특징 | 대표 |
|---|---|---|
| **Terlano / Terlaner** | 화산 반암(porphyry)·석영. **장기 숙성 화이트의 성지** | **Cantina Terlano** |
| **Valle Isarco / Eisacktaler** | 최북·최고지대. 케르너·실바너·리슬링 | **Abbazia di Novacella**, Kuenhof, Köfererhof |
| **Santa Maddalena / St. Magdalener** | 볼차노 언덕. 스키아바 | Cantina Bolzano |
| **Lago di Caldaro / Kalterersee** | 호수 주변, 스키아바 | |
| **Val Venosta / Vinschgau** | 극서부, 극소량 | Falkenstein |
| **Meranese** | 메라노 주변 | |

## 1-3. 핵심 생산자

| 생산자 | 대표 와인 |
|---|---|
| **Cantina Terlano** | **Vorberg**(피노 비앙코 리제르바), Nova Domus, **Rarità**(10년 이상 숙성 후 출시) |
| **Cantina Tramin** | **Nussbaumer**(게뷔르츠트라미너), Epokale |
| **Hofstätter** | **Barthenau Vigna S. Urbano** (이탈리아 최고 피노 네로 중 하나) |
| **Alois Lageder** | 비오디나미, Löwengang |
| **Elena Walch** | Castel Ringberg, Kastelaz |
| **Manincor** | 비오디나미 |
| **Franz Haas** | 피노 네로 |
| **Abbazia di Novacella** | 수도원 와이너리, 케르너·실바너 |
| Kuenhof · Köfererhof · Cantina Girlan · Cantina San Michele Appiano | |

> 알토아디제는 **협동조합(Cantina)의 품질이 매우 높은** 드문 지역이다. 조합원이 소규모 밭을 정성껏 관리하는 구조가 정착했다.

# 2. 트렌티노 Trentino

알토아디제 남쪽. 더 따뜻하고 생산량이 많으며, **스파클링**이 강점.

| DOC(G) | 내용 | 생산자 |
|---|---|---|
| **Trento DOC** | **메토도 클라시코 스파클링**. 샤르도네·피노 네로. 프란차코르타와 함께 이탈리아 양대 스파클링 | **Ferrari**(Giulio Ferrari Riserva del Fondatore), Rotari, Cesarini Sforza, Letrari |
| **Teroldego Rotaliano DOC** | **테롤데고** 품종. 로탈리아나 평야의 자갈밭. 짙고 신선 | **Elisabetta Foradori**(Granato, Morei) |
| **Trentino DOC** | 광역. 마르체미노, 노시올라, 샤르도네 | |
| **Vino Santo Trentino** | 노시올라 품종 건조 스위트 | |

> **Elisabetta Foradori**는 테롤데고를 무명 품종에서 세계적 품종으로 끌어올린 인물. 암포라 숙성·비오디나미로 유명하다.

# 3. 프리울리베네치아줄리아 Friuli-Venezia Giulia

이탈리아 화이트의 정점이자 **오렌지 와인(스킨 콘택트)의 발상지**.

| 항목 | 내용 |
|---|---|
| 위치 | 슬로베니아 국경. 알프스가 북풍을 막고 아드리아해가 온기를 준다 |
| 토양 | **폰카(ponca)** — 이회토와 사암이 층층이 쌓인 이 지역 고유 토양 |
| 특징 | 1970년대 **"화이트 와인 혁명"**(저온 발효·환원적 양조)의 진원지 |

## 3-1. 품종

| 품종 | 성격 |
|---|---|
| **프리울라노 Friulano** | 이 지역의 얼굴. 아몬드·풀향. (2007년까지 "Tocai Friulano") |
| **리볼라 지알라 Ribolla Gialla** | 산도 높고 껍질이 두꺼워 오렌지 와인에 적합 |
| **말바지아 이스트리아나** | |
| **피콜리트 Picolit** | 희귀 스위트 품종 |
| **베르두초 Verduzzo** | 스위트(라만돌로) |
| **레포스코 달 페둔콜로 로소 Refosco** | 레드. 자두·허브 |
| **스키오페티노 Schioppettino** | 레드. 후추향 |
| **피뇰로 Pignolo · 타첼렌게 Tazzelenghe** | 희귀 레드, 탄닌 강함 |
| 소비뇽, 피노 그리조, 샤르도네 | 국제품종도 높은 수준 |

## 3-2. 주요 DOC

| DOC(G) | 내용 | 생산자 |
|---|---|---|
| **Collio DOC** (Collio Goriziano) | 슬로베니아 국경의 언덕. 프리울리 최고 구역 | **Josko Gravner**, **Radikon**, **Damijan Podversic**, **La Castellada**, Schiopetto, Borgo del Tiglio, Venica & Venica |
| **Friuli Colli Orientali DOC** | 콜리오 북쪽 | **Miani**(Enzo Pontoni), Ronco del Gnemiz, Le Due Terre, Vignai da Duline |
| **Ramandolo DOCG** | 베르두초 스위트 | Dario Coos |
| **Rosazzo DOCG** | 프리울라노 중심 블렌드 | Livio Felluga(Terre Alte) |
| **Colli Orientali Picolit DOCG** | 피콜리트 스위트 | |
| **Friuli Isonzo DOC** | 평야, 자갈 | Vie di Romans, Ronco del Gelso |
| **Carso DOC** | 트리에스테 인근 석회암 카르스트 지형. **비토프스카**, 테라노 | **Vodopivec**, **Zidarich**, Skerk |
| **Friuli Grave DOC** | 최대 면적, 대량생산 | |

## 3-3. 오렌지 와인 (Vino Macerato)

화이트 품종을 **껍질과 함께 오래 침용**해 만드는 와인. 색이 호박빛이고 탄닌이 있다.

| 생산자 | 방식 |
|---|---|
| **Josko Gravner** | **조지아식 크베브리(암포라)**를 땅에 묻어 6개월 침용, 6년 숙성. 오렌지 와인 운동의 상징 |
| **Stanko / Saša Radikon** | 대형 오크통에서 3개월 침용, 무아황산 |
| **Damijan Podversic · La Castellada · Dario Prinčič** | |
| **Paraschos · Franco Terpin** | |

> 국경 너머 슬로베니아의 **브르다(Brda)**·**비파바** 지역과 사실상 같은 테루아이며, 두 나라 생산자들이 함께 이 운동을 만들었다.
