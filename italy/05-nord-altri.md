# 품종 Vitigni 비티니

> 네 지역이 성격상 공통점이 거의 없다. **알프스 고산(발텔리나·발레다오스타)**, **스파클링(프란차코르타)**, **평야의 레드 스파클링(람브루스코)**, **해안 절벽(리구리아)** — 각각 다른 품종군을 본다.

| 지역 | 주력 품종 | 성격 |
|---|---|---|
| **Franciacorta 프란차코르타** | 샤르도네 · 피노 네로 · 피노 비앙코 | 메토도 클라시코 |
| **Valtellina 발텔리나** | **Chiavennasca 키아벤나스카**(= 네비올로) | 알프스 급경사 |
| **Emilia 에밀리아** | **Lambrusco 람브루스코** (여러 아품종) | 레드 스파클링 |
| **Romagna 로마냐** | 산조베제 · **Albana 알바나** | |
| **Liguria 리구리아** | **Vermentino 베르멘티노 · Pigato 피가토 · Rossese 로세제** | 해안 |
| **Valle d'Aosta 발레다오스타** | **Prié Blanc 프리에 블랑 · Petit Rouge 프티 루주 · Fumin 푸민** | 유럽 최고지대 |

## 1. 프란차코르타의 품종

| 품종 | 역할 |
|---|---|
| **Chardonnay 샤르도네** | 주력. 산도·미네랄·숙성력 |
| **Pinot Nero 피노 네로** | 몸통·구조. 로제에 35% 이상 |
| **Pinot Bianco 피노 비앙코** | 최대 50%까지. 부드러움 |
| **Erbamat 에르바마트** | **2017년 추가된 토착 품종.** 극단적으로 늦게 익고 산도가 높아 **온난화 대응용**으로 최대 10% 허용 |

> **Satèn 사텐**은 프란차코르타 고유의 스타일이다. **피노 네로를 쓰지 않고 화이트 품종만**으로 만들며, 기압을 **4.5 bar 이하**(일반 6 bar)로 낮춰 거품을 부드럽게 한다. 이름은 "새틴(비단)"에서 왔다.

> 최소 숙성이 **논빈티지 18개월**로 샹파뉴(15개월)보다 길다. 리제르바는 60개월.

## 2. 발텔리나 — 알프스의 네비올로

| 항목 | 내용 |

| **Sforzato 스포르차토 (Sfursat 스푸르사트)** | 포도를 **3개월 이상 건조 후 발효**한 드라이 레드. 알코올 14~16%. **"알프스의 아마로네"** |

| **Maroggia 마로자** | 가장 작다 |

## 3. 람브루스코 — 하나가 아니라 여러 품종

**Lambrusco 람브루스코**는 단일 품종이 아니라 **야생 포도(vitis labrusca가 아닌 vitis vinifera 계열)에서 갈라진 품종군**의 총칭이다. 아품종마다 색과 구조가 크게 다르다.

| 아품종 | DOC | 성격 |
|---|---|---|
| **Lambrusco di Sorbara 람브루스코 디 소르바라** | Sorbara | **가장 옅은 색, 가장 높은 산도.** 로제에 가깝고 우아하다. 꽃떨이가 심해 수확량이 적다 |
| **Lambrusco Grasparossa 람브루스코 그라스파로사** | Castelvetro | **가장 진하고 탄닌이 있다.** 언덕 지대 |
| **Lambrusco Salamino 람브루스코 살라미노** | Santa Croce | 중간. 송이가 살라미를 닮았다고 이름이 붙었다 |
| **Lambrusco Maestri · Marani · Montericco** | | 블렌딩용 |

> **드라이(secco 세코) 람브루스코를 볼 것** — 1970~80년대 미국 시장을 겨냥한 단맛 대량생산이 이미지를 망가뜨렸다. 제대로 만든 것은 **완전히 드라이하고 거품이 섬세하며 산도가 높다.** 에밀리아의 기름진 음식(프로슈토·파르미자노·라구)과의 궁합이 이 와인의 존재 이유다.

| 양조 | 내용 |
|---|---|
| **Metodo Martinotti 메토도 마르티노티** | 탱크 발효. 대부분 |
| **Metodo Ancestrale 메토도 안체스트랄레** | 병내 재발효, 앙금째. Camillo Donati 카밀로 도나티 등 |
| **Metodo Classico** | Cantina della Volta 칸티나 델라 볼타 |

# 1. 롬바르디아 Lombardia

## 1-1. 프란차코르타 Franciacorta DOCG

**이탈리아 최고의 메토도 클라시코 스파클링.** 이세오 호수 남쪽 빙퇴석 언덕.

| 항목 | 내용 |
|---|---|
| 품종 | 샤르도네, 피노 네로, **피노 비앙코**, (Erbamat 에르바마트 소량) |
| 양조 | **병내 2차 발효** |
| 최소 숙성 | **18개월** (논빈티지) — 샹파뉴(15개월)보다 길다 |
| Millesimato 밀레시마토 | 30개월 |
| Riserva | **60개월** |

| 스타일 | 내용 |
|---|---|
| **Satèn 사텐** | **피노 네로 없이 화이트 품종만**, 기압 4.5 이하로 낮춰 부드럽게. 프란차코르타 고유 |
| **Rosé** | 피노 네로 35% 이상 |
| **Dosaggio Zero / Pas Dosé 도사조 제로 / 파 도제** | 당 첨가 없음 |

**핵심 생산자**: **Ca' del Bosco 카 델 보스코**(Annamaria Clementi 안나마리아 클레멘티) · **Bellavista 벨라비스타**(Vittorio Moretti 비토리오 모레티) · **Ferghettina 페르게티나** · Barone Pizzini 바로네 피치니(유기농 선구) · Contadi Castaldi 콘타디 카스탈디 · Monte Rossa 몬테 로사 · **Arcari + Danesi 아르카리 + 다네시**

## 1-2. 발텔리나 Valtellina

알프스 계곡의 **급경사 계단밭**. 네비올로를 현지에서 **키아벤나스카(Chiavennasca 키아벤나스카)**라 부른다.

| DOCG | 내용 |
|---|---|
| **Valtellina Superiore 발텔리나 수페리오레 DOCG** | 5개 하위 구역: **Sassella 사셀라 · Grumello 그루멜로 · Inferno 인페르노 · Valgella 발젤라 · Maroggia 마로자** |
| **Sforzato (Sfursat) di Valtellina 스포르차토(스푸르사트) 디 발텔리나 DOCG** | 포도를 **건조 후 발효**한 드라이 레드. "알프스의 아마로네" |

# 2. 에밀리아로마냐 Emilia-Romagna

## 2-1. 람브루스코 Lambrusco

**진지하게 볼 가치가 있는 레드 스파클링.** 1970~80년대 단맛 대량생산 이미지 때문에 저평가되었지만, 드라이(secco 세코) 버전은 전혀 다른 와인이다.

| DOC | 품종 | 성격 |
|---|---|---|
| **Lambrusco di Sorbara 람브루스코 디 소르바라** | 람브루스코 디 소르바라 | **가장 옅은 색·높은 산도**. 로제에 가깝고 우아 |
| **Lambrusco Grasparossa di Castelvetro 람브루스코 그라스파로사 디 카스텔베트로** | 그라스파로사 | 가장 진하고 탄닌 있음 |
| **Lambrusco Salamino di Santa Croce 람브루스코 살라미노 디 산타 크로체** | 살라미노 | 중간 |
| **Lambrusco Mantovano 람브루스코 만토바노** (롬바르디아) | | |

> 좋은 람브루스코는 **드라이하고 거품이 섬세하며 신선한 산도**를 지닌다. 에밀리아의 기름진 음식(프로슈토, 파르미자노, 라구)과의 궁합이 뛰어나다.

**핵심 생산자**: **Cleto Chiarli 클레토 키아를리** · **Paltrinieri 팔트리니에리** · **Vittorio Graziano 비토리오 그라치아노** · Camillo Donati 카밀로 도나티 · Cantina della Volta 칸티나 델라 볼타

# 4. 발레다오스타 Valle d'Aosta
