# 1. 롬바르디아 Lombardia

## 1-1. 프란차코르타 Franciacorta DOCG

**이탈리아 최고의 메토도 클라시코 스파클링.** 이세오 호수 남쪽 빙퇴석 언덕.

| 항목 | 내용 |
|---|---|
| 품종 | 샤르도네, 피노 네로, **피노 비앙코**, (에르바마트 소량) |
| 양조 | **병내 2차 발효** |
| 최소 숙성 | **18개월** (논빈티지) — 샹파뉴(15개월)보다 길다 |
| Millesimato | 30개월 |
| Riserva | **60개월** |

| 스타일 | 내용 |
|---|---|
| **Satèn** | **피노 네로 없이 화이트 품종만**, 기압 4.5 이하로 낮춰 부드럽게. 프란차코르타 고유 |
| **Rosé** | 피노 네로 35% 이상 |
| **Dosaggio Zero / Pas Dosé** | 당 첨가 없음 |

**핵심 생산자**: **Ca' del Bosco**(Annamaria Clementi) · **Bellavista**(Vittorio Moretti) · **Ferghettina** · Barone Pizzini(유기농 선구) · Contadi Castaldi · Monte Rossa · **Arcari + Danesi**

> 인근의 **Curtefranca DOC**는 같은 지역의 스틸 와인.

## 1-2. 발텔리나 Valtellina

알프스 계곡의 **급경사 계단밭**. 네비올로를 현지에서 **키아벤나스카(Chiavennasca)**라 부른다.

| DOCG | 내용 |
|---|---|
| **Valtellina Superiore DOCG** | 5개 하위 구역: **Sassella · Grumello · Inferno · Valgella · Maroggia** |
| **Sforzato (Sfursat) di Valtellina DOCG** | 포도를 **건조 후 발효**한 드라이 레드. "알프스의 아마로네" |
| Rosso di Valtellina DOC | 기본 등급 |

바롤로보다 **가볍고 산도가 높으며 향기롭다**. 알프스 고산의 서늘함이 그대로 드러난다.

**핵심 생산자**: **Ar.Pe.Pe.**(전통주의의 정점) · Nino Negri(5 Stelle Sfursat) · Sandro Fay · **Dirupi** · Mamete Prevostini

## 1-3. 그 밖의 롬바르디아

| DOC(G) | 내용 |
|---|---|
| **Oltrepò Pavese DOC / Metodo Classico DOCG** | 피노 네로 재배 면적 이탈리아 최대. 스파클링·스틸 |
| **Lugana DOC** | 가르다 호수 남안(베네토와 공유). 투르비아나 |
| **Moscato di Scanzo DOCG** | 베르가모. 이탈리아 최소 DOCG 중 하나, 건조 스위트 레드 |

# 2. 에밀리아로마냐 Emilia-Romagna

## 2-1. 람브루스코 Lambrusco

**진지하게 볼 가치가 있는 레드 스파클링.** 1970~80년대 단맛 대량생산 이미지 때문에 저평가되었지만, 드라이(secco) 버전은 전혀 다른 와인이다.

| DOC | 품종 | 성격 |
|---|---|---|
| **Lambrusco di Sorbara** | 람브루스코 디 소르바라 | **가장 옅은 색·높은 산도**. 로제에 가깝고 우아 |
| **Lambrusco Grasparossa di Castelvetro** | 그라스파로사 | 가장 진하고 탄닌 있음 |
| **Lambrusco Salamino di Santa Croce** | 살라미노 | 중간 |
| **Lambrusco Mantovano** (롬바르디아) | | |

> 좋은 람브루스코는 **드라이하고 거품이 섬세하며 신선한 산도**를 지닌다. 에밀리아의 기름진 음식(프로슈토, 파르미자노, 라구)과의 궁합이 뛰어나다.

**핵심 생산자**: **Cleto Chiarli** · **Paltrinieri** · **Vittorio Graziano** · Camillo Donati · Cantina della Volta

## 2-2. 로마냐 Romagna

| DOC(G) | 내용 | 생산자 |
|---|---|---|
| **Romagna Sangiovese DOC** | 산조베제. 하위 구역 16개 중 **Predappio, Bertinoro, Modigliana**가 두각 | **Villa Papiano**, Fattoria Zerbina, Tre Monti, Noelia Ricci |
| **Romagna Albana DOCG** | **이탈리아 최초의 화이트 DOCG(1987)**. 알바나 품종, 드라이~파시토 | Fattoria Zerbina(Scacco Matto) |
| **Colli Bolognesi Pignoletto DOCG** | 피뇰레토(그레케토 젠틸레) | |

# 3. 리구리아 Liguria

가파른 해안 계단밭. 생산량이 매우 적어 대부분 현지 소비된다.

| DOC | 품종 | 내용 | 생산자 |
|---|---|---|---|
| **Cinque Terre DOC** | 보스코, 알바롤라, 베르멘티노 | 절벽 계단밭. 극한 농업 | Cantina Cinque Terre, Walter De Battè |
| **Cinque Terre Sciacchetrà** | 동일 | 건조 스위트, 극소량 | |
| **Rossese di Dolceacqua DOC** | **로세제** | 프랑스 국경. 가볍고 향기로운 레드 | **Maccario Dringenberg**, Terre Bianche |
| **Riviera Ligure di Ponente DOC** | **피가토**, 베르멘티노 | 짠맛 있는 화이트 | Bruna, Punta Crena |
| **Colli di Luni DOC** | 베르멘티노 | 토스카나 접경 | Lunae Bosoni |

# 4. 발레다오스타 Valle d'Aosta

이탈리아 **최소 생산량** 주. 알프스 계곡의 극한 재배 환경.

| 내용 | |
|---|---|
| **Blanc de Morgex et de La Salle** | **유럽에서 가장 높은 포도밭**(최고 1,200 m). 프리에 블랑 품종. 필록세라가 살지 못해 **접목하지 않은 자근 포도나무** |
| 토착 레드 | **푸민 Fumin**, **프티 루주 Petit Rouge**(Torrette), **코르날랭 Cornalin**, **프레미 루주** |
| 토착 화이트 | 프티 아르빈, 프리에 블랑 |
| 국제품종 | 피노 그리조(Malvoisie), 뮈스카, 감메이 |

**핵심 생산자**: **Cave Mont Blanc de Morgex et La Salle** · **Les Crêtes** · **Grosjean** · Ermes Pavese · Château Feuillet

> AOC 명칭이 **프랑스어**로 표기된다(Valle d'Aosta / Vallée d'Aoste DOC). 프랑스어가 공용어인 자치주다.
