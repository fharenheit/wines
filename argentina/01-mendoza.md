# 아르헨티나 — 멘도사

> 아르헨티나 와인의 **약 70%**가 여기서 나온다. 그러나 "멘도사"는 남북 250km, 고도 450~1,700m를 아우르는 이름이라 그 자체로는 아무것도 말해주지 않는다. **어느 고도, 어느 IG인가**를 봐야 한다.

## 1. 멘도사의 다섯 권역

| 권역 | 원어 | 고도 | 성격 |
|---|---|---|---|
| **북부 멘도사** | Mendoza Norte | 600~750m | 더움. 대량생산 |
| **첫 지대** | **Primera Zona 프리메라 소나** | 800~1,100m | **마이푸 + 루한 데 쿠요.** 역사적 심장 |
| **동부** | Zona Este 소나 에스테 | 600~750m | 최대 면적. 벌크·크리오야 |
| **우코 밸리** | **Valle de Uco 바예 데 우코** | 900~1,700m | **현재의 정점** |
| **남부** | Zona Sur(San Rafael) | 450~800m | 산 라파엘 DOC |

## 2. Maipú 마이푸

| 항목 | 내용 |
|---|---|
| 위치 | 멘도사 시 남동쪽, 해발 700~900m |
| 역사 | 1853년 푸제의 시험 포도밭이 있던 곳. **아르헨티나 근대 와인의 출발점** |
| 토양 | 자갈·모래 위 충적토 |
| 특징 | **자근 노목**이 많다. 100년 넘은 말벡·카베르네 밭이 남아 있다 |
| 스타일 | 우코보다 따뜻해 **부드럽고 흙내가 있는 말벡**, 견고한 카베르네 소비뇽 |
| 소구역 | **Barrancas 바랑카스** · Cruz de Piedra · Lunlunta 룬룬타 |

**생산자**: **Trapiche 트라피체**(1883), **Zuccardi 수카르디**(원래 마이푸), **Bodega Santa Ana**, Trivento

## 3. Luján de Cuyo 루한 데 쿠요 — 아르헨티나 최초의 DOC

| 항목 | 내용 |
|---|---|
| 승격 | **1993년 DOC** — 아르헨티나 최초. **말벡 전용** |
| 고도 | 800~1,100m |
| 별칭 | **"La Cuna del Malbec 라 쿠나 델 말벡"(말벡의 요람)** |
| 토양 | 안데스에서 내려온 **자갈 + 얕은 석회질 표층**, 모래 |
| 스타일 | **자두·제비꽃·검은 과일**에 **벨벳 같은 탄닌.** 우코보다 둥글고 무게가 있다 |

### 주요 소구역(IG)

| IG | 고도 | 성격 |
|---|---|---|
| **Agrelo 아그렐로** | 950~1,050m | 가장 유명. 구조적인 말벡·카베르네 |
| **Las Compuertas 라스 콤푸에르타스** | 1,050~1,100m | **1920년대 노목**. 섬세하고 향기롭다 |
| **Perdriel 페르드리엘** | 900~1,000m | 균형형 |
| **Vistalba 비스탈바** | 1,000~1,100m | 서늘한 상단 |
| **Ugarteche · Carrodilla** | 900m 내외 | |

**생산자**: **Catena Zapata 카테나 사파타**(피라미드 와이너리, 아그렐로), **Cheval des Andes 슈발 데 안데스**(슈발 블랑 + 테라자스), **Achaval-Ferrer 아차발 페레르**, **Norton**, **Luigi Bosca**, **Terrazas de los Andes**, Alta Vista, Nieto Senetiner

> **Cheval des Andes 슈발 데 안데스** — 생테밀리옹 **Château Cheval Blanc 샤토 슈발 블랑**과 LVMH의 테라자스가 1999년 시작한 합작. 말벡 + 카베르네 소비뇽 + 프티 베르도를 **보르도식 블렌딩**으로 만든다. "안데스의 슈발 블랑".

## 4. Valle de Uco 우코 밸리 — 현재의 최전선

> 1990년대까지 거의 비어 있던 고지대 사막. 지금은 **아르헨티나에서 가장 비싼 땅**이다.

| 항목 | 내용 |
|---|---|
| 위치 | 멘도사 남서쪽 100km, 안데스 바로 아래 |
| 고도 | **900~1,700m** — 아르헨티나 최고급 말벡의 대부분 |
| 기온 | 루한보다 평균 2~3℃ 낮다. 일교차 20℃ 이상 |
| **토양** | **석회질(calcáreo 칼카레오)과 큰 돌(cantos rodados 칸토스 로다도스)** — 아르헨티나에서 석회질이 나오는 거의 유일한 곳 |
| 위험 | **서리와 우박.** 방상팬·방충망이 필수 |
| 스타일 | 말벡이 **꽃·허브·짠맛**을 띠고 산도가 높다. **알코올이 낮아진다**(13.5% 내외) |

### 우코의 세 행정구역과 IG

| 구역 | 주요 IG | 고도 | 성격 |
|---|---|---|---|
| **Tupungato 투풍가토** | **Gualtallary 구알타야리** | 1,200~1,700m | **가장 유명.** 백악질 석회, 강한 긴장. 카베르네 프랑·샤르도네도 |
| | **El Peral · Villa Bastías** | 1,100~1,300m | |
| **Tunuyán 투누얀** | **Los Chacayes 로스 차카예스** | 1,100~1,400m | 화강암·큰 돌. 향기롭고 구조적 |
| | Vista Flores | 1,000~1,100m | |
| **San Carlos 산 카를로스** | **Paraje Altamira 파라헤 알타미라** | 1,050~1,200m | **2013년 IG 승인.** 두꺼운 석회 피막(caliche)의 자갈 — 짠맛과 광물감 |
| | **La Consulta 라 콘술타** | 950~1,100m | 전통적. 균형 |
| | **San Pablo 산 파블로** | 1,300~1,700m | **우코 최고지대 IG**(2019). 극단적 산도 |

> **Paraje Altamira 파라헤 알타미라**는 아르헨티나에서 **테루아 논쟁이 처음 벌어진 이름**이다. 원래 경계가 행정구역으로 그어져 있던 것을, 생산자들이 **투누얀 강의 옛 충적선(석회질 자갈이 끝나는 선)**을 기준으로 다시 그어달라고 요구해 2013년 재획정되었다. **아르헨티나가 "품종의 나라"에서 "장소의 나라"로 넘어간 분기점**으로 평가된다.

**생산자**: **Zuccardi Valle de Uco 수카르디**(Piedra Infinita — 파라헤 알타미라), **Catena Zapata Adrianna Vineyard 아드리아나 밭**(구알타야리 1,500m — White Bones · White Stones · Fortuna Terrae), **Bodega Chacra**는 파타고니아, **Salentein 살렌테인**, **Clos de los Siete 클로 데 로스 시에테**(미셸 롤랑 주도 7인 프로젝트), **Bodega Aleanna(El Enemigo)**, **Per Se**, **Matías Riccitelli**, **Alto Las Hormigas**, Pulenta, Andeluna, SuperUco

> **Adrianna Vineyard 아드리아나 밭** — 니콜라스 카테나가 1992년 구알타야리 1,500m에 심은 밭. "남미의 그랑 크뤼"라 불린다. 밭 안의 토양 차이만으로 **White Bones**(석회화한 소의 뼈가 섞인 구획)와 **White Stones**(둥근 돌)를 따로 병입한다.

## 5. San Rafael 산 라파엘

| 항목 | 내용 |
|---|---|
| 위치 | 멘도사 남쪽 230km, 해발 450~800m |
| 지위 | **DOC**(루한 데 쿠요와 함께 단 둘) |
| 기후 | 서늘하지만 **우박 피해가 심각**해 면적이 줄었다 |
| 품종 | 말벡 · 카베르네 소비뇽 · **샤르도네** · 슈냉 블랑 |

**생산자**: **Bianchi**, Suter, Jean Rivier, Algodon

# 6. 품종 — 멘도사에서의 성격

| 품종 | 어디서 | 성격 |
|---|---|---|
| **Malbec 말벡** | **루한 데 쿠요** | **자두·블랙베리·제비꽃·코코아.** 벨벳 탄닌, 둥근 중간 맛. 알코올 14%대 |
| | **우코(파라헤 알타미라·구알타야리)** | **붉은 과일·꽃·마른 허브에 짠맛.** 산도가 높고 탄닌이 가늘게 길다. 13.5% 내외 |
| | 마이푸 노목 | 흙·가죽·말린 자두. 더 부드럽다 |
| | *프랑스 카오르와의 차이* | 카오르는 **철·타르·거친 탄닌**, 멘도사는 **꽃과 완숙 과일**. 같은 품종이 고도와 일조로 완전히 달라진 예 |
| **Cabernet Franc 카베르네 프랑** | **구알타야리 · 로스 차카예스** | **2010년대 최대의 발견.** 라즈베리·고추·연필심. 루아르보다 익고 보르도보다 향기롭다. 아르헨티나가 말벡 다음으로 내세우는 품종 |
| **Cabernet Sauvignon 카베르네 소비뇽** | 아그렐로 · 우코 상단 | 고도에서 피라진이 남지 않을 만큼 익으면서 **카시스·민트**가 뚜렷하다 |
| **Bonarda 보나르다** | 동부 멘도사 · 산 후안 | 짙은 색, **낮은 탄닌, 즙 많은 검은 과일.** 노목에서 진지한 와인이 나오기 시작했다 |
| **Chardonnay 샤르도네** | **구알타야리 · 산 파블로** | 백악질에서 **감귤·분필·긴 산도.** 오크를 줄이는 추세. 아르헨티나 최고의 화이트 |
| **Semillón 세미용** | 우코 · 파타고니아 노목 | 밀랍·감귤. 1930~40년대 밭이 남아 있다 |
| **Petit Verdot · Syrah · Tempranillo** | 다양 | 블렌딩 또는 소량 |
| **Torrontés 토론테스** | 우코 소량 | 살타 쪽이 본령 → [북부·파타고니아 문서](02-north-patagonia.md) |

## 말벡을 고도로 읽기

| 고도 | 향 | 구조 | 알코올 |
|---|---|---|---|
| 700~900m (마이푸) | 잘 익은 자두 · 흙 | 부드럽다 | 14~14.5% |
| 900~1,100m (루한) | 자두 · 제비꽃 · 코코아 | 벨벳, 균형 | 14~14.5% |
| 1,100~1,400m (알타미라·차카예스) | 붉은 과일 · 꽃 · 짠맛 | 가늘고 길다 | 13.5~14% |
| 1,400~1,700m (구알타야리 상단) | 허브 · 흑후추 · 광물 | 날카롭고 좁다 | 13~13.5% |

> **오크의 후퇴** — 2000년대 아르헨티나 말벡의 전형은 **새 프렌치 오크 100%, 15% 알코올**이었다. 지금 최상급은 **콘크리트 에그·푸드르·암포라**를 쓰고 새 오크를 20~30%로 낮춘다. 수카르디의 피에드라 인피니타는 **오크를 전혀 쓰지 않는다.**
