# 아르헨티나 — 북부와 파타고니아

> 멘도사 밖의 아르헨티나는 **두 극단**이다. 북쪽으로는 세계에서 가장 높은 포도밭이, 남쪽으로는 세계에서 가장 남쪽에 가까운 포도밭이 있다.

## 1. Salta 살타 — 세계 최고지대

| 항목 | 내용 |
|---|---|
| 위치 | 아르헨티나 북서부, 남위 26° — **열대에 가까운 위도** |
| 성립 조건 | 위도의 더위를 **고도가 상쇄한다.** 1,700m 아래로는 포도가 제대로 익지 않는다 |
| 고도 | **1,700~3,111m** |
| 일교차 | **20~25℃** — 세계 최대 수준 |
| 강수 | 연 150~200mm. 극도로 건조하고 **일조가 강하다**(연 300일 이상) |
| 결과 | **껍질이 두껍고 색이 극단적으로 진하며 향이 강렬한** 포도 |

### Valles Calchaquíes 바예스 칼차키에스 (칼차키 계곡)

살타·투쿠만·카타마르카 세 주에 걸친 계곡군으로, 살타 와인의 실체다.

| 소산지 | 고도 | 성격 |
|---|---|---|
| **Cafayate 카파야테** | 1,600~2,000m | **중심지.** 토론테스와 말벡 |
| **Colomé 콜로메** | 2,200~3,111m | **Altura Máxima 알투라 막시마 밭 = 해발 3,111m**, 세계 최고지대 상업 포도밭 |
| **Molinos 몰리노스** | 2,000~2,600m | |
| **Angastaco · San Carlos** | 1,700~2,100m | |
| **Tucumán(Amaicha) · Catamarca(Fiambalá)** | 1,700~2,000m | 남·북으로 이어진다 |

**생산자**: **Bodega Colomé 콜로메**(1831년 창립 — 아르헨티나 최고(最古) 와이너리 중 하나, 1998년 도널드 헤스 인수), **El Esteco**, **Bodega Amalaya**, **Piattelli**, **Yacochuya**(미셸 롤랑), **Tacuil**, **San Pedro de Yacochuya**

> **Colomé Altura Máxima 콜로메 알투라 막시마** — 해발 **3,111m**. 자외선이 해수면의 두 배 가까이 되어, 포도가 자기 방어로 안토시아닌과 탄닌을 극단적으로 축적한다. 그 결과 색은 잉크처럼 검고 향은 압도적이다.

## 2. La Rioja 라 리오하

| 항목 | 내용 |
|---|---|
| 위치 | 살타 남쪽, 스페인 리오하와는 무관한 동명 지역 |
| 중심 | **Valle de Famatina 바예 데 파마티나** (900~1,400m) |
| 품종 | **Torrontés Riojano 토론테스 리오하노** — 품종 이름이 여기서 왔다 |
| 구조 | 협동조합 중심(**La Riojana**는 남미 최대 규모의 공정무역·유기농 협동조합) |

## 3. San Juan 산 후안 — 생산량 2위

| 항목 | 내용 |
|---|---|
| 위치 | 멘도사 바로 북쪽. 생산량 **전국 2위**(약 20%) |
| 기후 | 멘도사보다 **덥고 더 건조하다.** 손다 바람이 특히 강하다 |
| 전통 | 오랫동안 벌크·베르무트·**셰리 스타일 주정강화**·농축과즙 산지 |
| 전환 | **Pedernal 페데르날 계곡**(1,250~1,500m)과 **Calingasta 칼링가스타**의 고지대 개척으로 품질 산지로 이동 중 |
| 품종 | **Syrah 시라**(아르헨티나 최고 수준) · **Bonarda 보나르다** · 말벡 · 비오니에 · 토론테스 |

**생산자**: **Callia**, **Finca Las Moras**, **Xumek**, Pyros(페데르날), Graffigna

> 아르헨티나에서 **시라를 진지하게 볼 곳은 산 후안**이다. 페데르날의 석회질 고지대 시라는 후추와 육류 향이 뚜렷하다.

## 4. Patagonia 파타고니아 — 남쪽의 서늘함

> 여기서는 고도가 아니라 **위도**가 서늘함을 만든다. 남위 38~45°, 해발 200~400m. **강한 바람**이 포도를 작고 두껍게 만든다.

| 주 | 산지 | 성격 |
|---|---|---|
| **Neuquén 네우켄** | **San Patricio del Chañar 산 파트리시오 델 차냐르** | 2000년대에 사막을 개간해 만든 신흥 산지. 말벡·피노 누아 |
| **Río Negro 리오 네그로** | **Alto Valle 알토 바예** | **1900년대 초 이민자들이 심은 노목.** 아르헨티나에서 가장 오래된 상업 포도밭 일부 |
| **Chubut 추부트** | Trevelin · Sarmiento | 남위 43° 이남. **아르헨티나 최남단.** 피노 누아·리슬링·샤르도네 |

| 항목 | 내용 |
|---|---|
| 기후 | **바람.** 시속 100km의 서풍이 일상 — 수확량을 줄이고 병해를 막는다 |
| 일조 | 여름 일조시간이 길다(남쪽이라 해가 늦게 진다) |
| 토양 | 리오 네그로 강의 충적 자갈, 석회질 |
| 품종 | **Pinot Noir 피노 누아** · **Malbec** · **Semillón 세미용**(노목) · 메를로 · 소비뇽 블랑 · **샤르도네** |

**생산자**: **Bodega Chacra 차크라**(피에로 인치사 델라 로케타 — 사시카이아 가문), **Noemía**(한스 빈딩디에르스 + 노에미 마로네 친사노), **Humberto Canale**(1909), **Bodega del Fin del Mundo**, **Schroeder**, Otronia(추부트, 남위 45°)

> **Bodega Chacra 차크라** — 2004년 피에로 인치사 델라 로케타가 **1932년과 1955년에 심은 방치된 피노 누아 밭**을 사들여 시작했다. 바이오다이내믹, 자근, 저개입. 밭 이름을 그대로 와인 이름으로 쓴다(**Treinta y Dos 트레인타 이 도스 = 32년**, **Cincuenta y Cinco = 55년**). 이후 **Jean-Marc Roulot 장마르크 룰로**(뫼르소)와 협업한 샤르도네로도 확장했다.

# 5. 품종 — 북부와 파타고니아에서의 성격

| 품종 | 어디서 | 성격 |
|---|---|---|
| **Torrontés 토론테스** | **카파야테 · 라 리오하** | **장미·오렌지꽃·백도의 폭발적인 향**에 **의외로 드라이하고 쓴맛이 도는 마무리.** 향만 보고 달 것이라 예상하면 배신당한다. 껍질 접촉을 최소화하고 저온 발효해야 쓴맛이 안 나온다. **어릴 때 마신다** |
| **Malbec 말벡**(살타) | 카파야테 · 콜로메 | 멘도사보다 **색이 검고 탄닌이 굵으며 향신료가 강하다.** 자외선이 만든 두꺼운 껍질. 알코올 14.5~15% |
| **Cabernet Sauvignon**(살타) | 카파야테 | 강렬하지만 거칠어질 수 있다. 블렌딩용이 많다 |
| **Tannat 타나** | 카파야테 | 소량이지만 고지대와 잘 맞는다 |
| **Syrah 시라** | **산 후안 페데르날** | **흑후추·올리브·훈연.** 아르헨티나 시라의 기준점 |
| **Bonarda 보나르다** | 산 후안 · 동부 멘도사 | 진한 색에 부드러운 탄닌, 즙 많은 자두. **아르헨티나에서 두 번째로 많이 심는 레드**인데 저평가되어 있다 |
| **Pinot Noir 피노 누아** | **파타고니아(리오 네그로 · 네우켄 · 추부트)** | **남미 최고 수준.** 붉은 과일·장미·흙, 산도가 높고 몸이 가볍다. 칠레 레이다보다 부르고뉴에 가깝다 |
| **Semillón 세미용** | **리오 네그로 노목** | 밀랍·감귤·아몬드. 1930~40년대 밭. 아르헨티나에서 가장 저평가된 화이트 |
| **Chardonnay 샤르도네** | 추부트 · 리오 네그로 | 날카로운 산도, 서늘한 스타일 |
| **Riesling · Merlot** | 파타고니아 | 소량 |

## 세 지역 대비

| | **살타(북부)** | **산 후안** | **파타고니아** |
|---|---|---|---|
| 서늘함의 원천 | **고도**(1,700~3,111m) | 고도(페데르날) | **위도 + 바람** |
| 대표 | **토론테스 · 진한 말벡** | **시라 · 보나르다** | **피노 누아 · 세미용** |
| 알코올 | 14.5~15% | 14~15% | **13~13.5%** |
| 성격 | 강렬·응축·향신료 | 따뜻하고 후추 | **가늘고 향기롭고 산도 높다** |

> **아르헨티나를 말벡 하나로 요약하면 절반을 놓친다.** 살타의 토론테스, 산 후안의 시라, 파타고니아의 피노 누아와 세미용은 각각 다른 나라의 와인처럼 들린다.
