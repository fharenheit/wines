# 칠레 — 해안 산지와 남부

> 1990년대까지 칠레 와인은 **중앙 계곡의 따뜻한 카베르네**로 요약되었다. 지난 30년의 이야기는 두 방향의 탈출이다 — **서쪽(바다)으로**, 그리고 **남쪽(추위)으로**.

## 1. Aconcagua 아콩카과

산티아고 북쪽, 남미 최고봉 **Aconcagua 아콩카과 산(6,961m)**에서 이름을 땄다. 하나의 계곡 안에 **가장 더운 곳과 가장 서늘한 곳이 함께** 있다.

| 항목 | 내용 |
|---|---|
| 구조 | 동쪽 **Aconcagua Andes**(더움) — 중앙 **Entre Cordilleras** — 서쪽 **Aconcagua Costa**(서늘) |
| 대표 | **Errázuriz 에라수리스**(1870년 창립, 계곡의 중심), **Seña 세냐**(에라수리스 + 몬다비 합작), **Viñedo Chadwick**은 마이포 소속 |
| 동쪽 | **카베르네 소비뇽 · 시라** — 풍만하고 농익은 스타일 |
| 서쪽(Costa) | 2005년 이후 개척. **피노 누아 · 소비뇽 블랑 · 서늘한 시라** |

> **Seña 세냐(1995)** — 에두아르도 채드윅과 로버트 몬다비의 합작으로 시작한 칠레 최초의 "아이콘 와인" 중 하나. 카베르네에 카르메네르·말벡·프티 베르도를 섞는다. 2005년부터 바이오다이내믹.

## 2. Casablanca 카사블랑카

| 항목 | 내용 |
|---|---|
| 위치 | 산티아고와 발파라이소 사이, 바다에서 **20~30km** |
| 개척 | **1982년 파블로 모란데(Pablo Morandé)**가 처음 식재. "너무 춥다"는 통념을 깼다 |
| 기후 | 아침 안개, 오후 해풍. **중앙 계곡보다 성숙이 4~6주 늦다** |
| 위험 | **봄 서리** — 계곡 바닥에 냉기가 고인다. 방상팬·살수 필수 |
| 품종 | **Sauvignon Blanc · Chardonnay · Pinot Noir**, 서늘한 **Syrah** |
| 성격 | 소비뇽 블랑은 자몽·라임에 허브 — 말버러보다 덜 공격적, 상세르보다 더 과일 쪽 |

**생산자**: **Casas del Bosque**, **Kingston Family**, **Loma Larga**, Veramonte, Emiliana(유기농·바이오다이내믹), Villard

## 3. San Antonio · Leyda 산 안토니오 · 레이다

카사블랑카보다 **더 남쪽, 더 바다에 가깝다**(4~14km). 칠레 서늘 기후 와인의 **현재 최전선**이다.

| 항목 | 내용 |
|---|---|
| 승격 | **2002년 DO 지정.** Leyda 레이다는 그 안의 소구역 |
| 관건 | 물이 없었다. **1997년 마이포 강에서 8km 송수관**을 놓으면서 비로소 재배가 가능해졌다 |
| 토양 | 화강암 기반의 얇은 표토, 붉은 점토 |
| 품종 | **Sauvignon Blanc**(가장 짜릿하다) · **Pinot Noir** · **Syrah** · Chardonnay |
| 성격 | 소비뇽 블랑에 **부싯돌·염분**, 시라는 **후추·올리브·제비꽃**의 서늘한 북부 론 계열 |

**생산자**: **Viña Leyda**, **Matetic 마테틱**(바이오다이내믹, EQ 시라), **Casa Marín 카사 마린**(바다에서 4km — 칠레 최서단 포도밭), Garcés Silva(Amayna)

> **Casa Marín 카사 마린** — 마리아 루스 마린이 1999년 로 아반티노에 세운 밭. "바다에서 4km는 미친 짓"이라던 곳에서 소비뇽 블랑과 **게뷔르츠트라미너·리슬링**까지 성공시켰다.

## 4. Limarí 리마리 · Elqui 엘키 — 사막의 가장자리

칠레 최북단 산지. **아타카마 사막의 남쪽 끝**으로, 연강수량이 **100mm 이하**인 곳도 있다.

| | **Limarí 리마리** | **Elqui 엘키** |
|---|---|---|
| 위도 | 남위 약 30° | 남위 약 30° 이북 |
| 강수 | 연 100mm 안팎 — 관개 없이는 불가능 | 더 건조 |
| 특징 | **석회질 토양** — 칠레에서 드물다 | **고도**(최대 2,000m 이상) + **카만차카 안개** |
| 품종 | **Chardonnay**(칠레 최고 수준) · **Syrah** · 피노 누아 | **Syrah** · 소비뇽 블랑 · 카르메네르 |
| 성격 | 샤르도네에 **분필·염분**, 시라는 후추·피 | 시라에 **강한 산도와 향신료**. 고도 특유의 긴장 |

> 엘키는 원래 **피스코(pisco 피스코)** 증류용 포도 산지였다. 와인 재배는 1990년대 말에야 시작되었다.

**생산자**: **Tabalí 타발리**, **Maycas del Limarí**, **De Martino**(리마리), **Viña Falernia**, Mayu(엘키)

## 5. 남부 — Itata 이타타 · Bío Bío 비오비오 · Malleco 마예코

> 칠레에서 **가장 오래된 포도밭이 있는 곳이자 가장 새로운 곳**이다. 1550년대에 심었고, 400년 동안 잊혔다가 2010년대에 재발견되었다.

| 산지 | 성격 |
|---|---|
| **Itata 이타타** | **1550년대부터의 파이스·시나울트 노목**(일부 200년 이상). 화강암 토양, 자근, 부시 바인, 관개 없음 |
| **Bío Bío 비오비오** | 더 서늘하고 비가 많다. **리슬링 · 게뷔르츠트라미너 · 피노 누아 · 샤르도네** |
| **Malleco 마예코** | 남위 38°. 칠레 최남단 상업 산지. **샤르도네·피노 누아** |

### 이타타 재발견

| 항목 | 내용 |
|---|---|
| 역사 | 1550년대 스페인 정착민 식재. 20세기 내내 **벌크 와인·치차(chicha)용**으로 헐값에 팔렸다 |
| 전환 | 2010년대, 자연파 생산자들이 이 노목의 가치를 알아본다 |
| 재배 | **자근 · 무관개(secano) · 부시 바인 · 화강암** — 즉 유럽이 잃어버린 조건이 그대로 남아 있다 |
| 스타일 | **파이스**: 옅은 색, 낮은 알코올, 붉은 과일과 흙 — 가메·프리미티보의 가벼운 사촌<br>**시나울트**: 더 향기롭고 부드럽다 |

**생산자**: **Roberto Henríquez 로베르토 엔리케스**, **A Los Viñateros Bravos**(레오나르도 에라수리스), **Cacique Maravilla**, **Rogue Vine**, De Martino(Viejas Tinajas — **점토 항아리 tinaja 티나하** 발효), Bouchon(파이스 살바헤)

> **País Salvaje 파이스 살바헤("야생 파이스")** — 나무를 타고 올라가 자란 방치된 파이스 덩굴에서 수확한 와인. 부숑이 대표적이다.

### Malleco 마예코 — 한 사람이 연 산지

**Viña Aquitania 아키타니아**의 **Sol de Sol**(1995년 식재)이 남위 38°에서 샤르도네가 가능함을 증명했다. 이후 **William Fèvre 기욤 페브르**(샤블리)의 칠레 프로젝트 등이 뒤따랐다.

# 6. 품종 — 해안과 남부에서의 성격

| 품종 | 어디서 | 성격 |
|---|---|---|
| **Sauvignon Blanc 소비뇽 블랑** | **레이다 · 카사블랑카 · 카사 마린** | **자몽·라임·부싯돌·염분.** 말버러의 패션프루트만큼 폭발적이지 않고, 상세르보다 과일이 많다 — 그 중간의 칠레 스타일이 확립되었다 |
| **Chardonnay 샤르도네** | **리마리**(석회질) · 카사블랑카 · 마예코 | 리마리는 **분필·염분·감귤**로 칠레 최고 수준. 카사블랑카는 더 과일 쪽. 오크 사용이 1990년대보다 크게 줄었다 |
| **Pinot Noir 피노 누아** | **레이다 · 카사블랑카 · 비오비오** | 붉은 과일·허브·흙. 아직 부르고뉴급은 드물지만 **가격 대비 가장 발전이 빠른 품종** |
| **Syrah 시라** | **엘키 · 리마리 · 레이다 · 아콩카과 코스타** | **칠레의 진짜 놀라움.** 중앙 계곡의 잼 스타일과 정반대로 **흑후추·올리브·제비꽃·피** — 북부 론 계열. 알코올 13%대에서 마무리된다 |
| **País 파이스** | **이타타 · 마울레** | **옅은 색, 12~13% 알코올, 붉은 과일·흙·마른 잎.** 탄닌 낮고 산도 높다. 서늘하게 마신다 |
| **Cinsault 시나울트** | **이타타** | 파이스보다 향기롭고 부드럽다. 딸기·장미. **탄산 침용(carbonic)** 양조가 흔하다 |
| **Riesling · Gewürztraminer** | **비오비오 · 카사 마린** | 소량이지만 산도가 살아 있다 |
| **Cabernet Sauvignon** | 아콩카과 동쪽 | 여기서만 — 해안에서는 익지 않는다 |

## 스타일 대비

| | 중앙 계곡 | 해안·남부 |
|---|---|---|
| 대표 품종 | 카베르네 · 카르메네르 | 소비뇽 블랑 · 피노 · **서늘한 시라** · 파이스 |
| 알코올 | 14~14.5% | **12.5~13.5%** |
| 오크 | 새 오크 비중 높음 | 중고 오크 · 콘크리트 · **티나하** |
| 지향 | 국제적 완숙 | **산지 표현 · 저개입** |

> **두 흐름은 경쟁이 아니라 보완이다.** 칠레의 수출을 떠받치는 것은 여전히 중앙 계곡의 카베르네이고, 칠레의 평판을 바꾸고 있는 것은 해안과 남부다.
