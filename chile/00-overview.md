# 칠레 와인 개요

![칠레 주요 와인 산지 지도](../assets/chile-overview.svg)

> **자연이 만든 격리 상태.** 북쪽은 아타카마 사막, 동쪽은 안데스, 서쪽은 태평양, 남쪽은 빙하와 파타고니아. 이 네 겹의 장벽 덕분에 **필록세라가 한 번도 들어오지 않았고**, 세계에서 사실상 유일하게 **전 국토가 자근(pie franco) 재배**인 나라가 되었다.

## 1. 산지 제도

| 항목 | 내용 |
|---|---|
| 제도 | **DO (Denominación de Origen 데노미나시온 데 오리헨)**, 1995년 도입 |
| 성격 | **경계만 정한다.** 품종·수확량·양조법 규정 없음 — 미국 AVA·호주 GI와 같은 구조 |
| 라벨 규정 | 품종·빈티지·DO 모두 **75% 이상**(수출용은 관행적으로 85%) |

### 남북 위계 (전통 구분)

```
Región (레히온)  →  Subregión (수브레히온)  →  Zona (소나)  →  Área (아레아)
Valle Central    →  Valle de Rapel        →  Colchagua   →  Apalta
```

### 2011년 개편 — 동서 축의 도입

> 칠레의 진짜 변수는 **남북(위도)이 아니라 동서(바다와 안데스로부터의 거리)**라는 인식에서, 2011년 **동서 3구역 표기**가 추가되었다.

| 표기 | 원어 | 위치 | 성격 |
|---|---|---|---|
| **코스타** | **Costa 코스타** | 해안 산맥 서쪽 | 태평양 안개·훔볼트 한류. **서늘·고산도** |
| **엔트레 코르디예라스** | **Entre Cordilleras 엔트레 코르디예라스** | 두 산맥 사이 중앙 계곡 | 온난·건조. 전통적 대량 산지 |
| **안데스** | **Andes 안데스** | 안데스 산기슭 | **고도·큰 일교차.** 구조적 |

> **Humboldt Current 훔볼트 해류** — 남극에서 올라오는 한류로, 칠레 해안의 수온을 낮춰 **위도에 비해 극단적으로 서늘한 기후**를 만든다. 산티아고와 같은 위도인 카사블랑카가 피노 누아 산지가 되는 이유다.

## 2. 필록세라 없는 나라

| 항목 | 내용 |
|---|---|
| 상태 | **전 국토 자근(pie franco 피에 프랑코).** 대목에 접붙이지 않는다 |
| 이유 | 사막·산맥·바다·빙하의 4중 격리 + 엄격한 검역 |
| 의미 | **19세기 보르도에서 가져온 원래 클론**이 그대로 살아 있다 |
| 부산물 | **Carménère 카르메네르**가 보르도에서 소멸한 뒤 칠레에만 남았다 |

> **카르메네르의 재발견(1994)** — 칠레 메를로의 일부가 유난히 늦게 익고 맛이 다르다는 점이 오래 지적되었다. 1994년 몽펠리에의 장미셸 부르시코 교수가 DNA로 확인한 결과, 그것은 **보르도에서 필록세라 이후 사라진 카르메네르**였다. 1998년 칠레 정부가 별도 품종으로 공식 인정했다.

## 4. 스페인어 읽기

프랑스·스페인 문서와 같은 규칙이다. 칠레 지명에는 **마푸체어(Mapudungun)** 기원이 많다.

| 지명 | 발음 | 비고 |
|---|---|---|
| **Maipo** | 마이포 | 마푸체어 |
| **Colchagua** | 콜차과 | 마푸체어 |
| **Curicó** | 쿠리코 | "검은 물" |
| **Maule** | 마울레 | 마푸체어 |
| **Itata** | 이타타 | |
| **Bío Bío** | 비오비오 | |
| **Casablanca** | 카사블랑카 | 스페인어 "흰 집" |
| **Limarí** | 리마리 | |
| **Apalta** | 아팔타 | |

> 스페인어 읽기 규칙 전반은 **[스페인 개요 §4](../spain/00-overview.md)** 참조 — `j`=ㅎ, `ll`=이, `ñ`=니, `h`=묵음, `v`=ㅂ.

## 5. 역사 — 세 번의 전환

| 시기 | 사건 |
|---|---|
| **1548** | 스페인 선교사가 **País 파이스** 식재 |
| **1850~60년대** | 부유층이 보르도에서 묘목과 양조가를 들여온다. **카베르네·메를로·카르메네르·말벡**이 이때 들어왔다 |
| 1870년대 | **보르도에 필록세라.** 칠레는 무사 |
| 1938~1974 | 신규 식재 금지법. 산업 정체 |
| **1980년대** | Miguel Torres(스페인)가 스테인리스 탱크를 도입하며 현대화 시작 |
| 1990년대 | 수출 폭발. **"저렴하고 안정적인 카베르네"**로 자리 잡았다 |
| **1994** | 카르메네르 정체 확인 |
| **2000년대~** | **해안(카사블랑카·레이다)과 극남(이타타·비오비오)으로 확장** |
| **2010년대~** | **파이스·시나울트·카리냥 노목 재발견.** MOVI(독립 생산자 운동)·VIGNO(마울레 카리냥 협회) |

> **저가 이미지의 극복이 과제다.** 칠레는 오랫동안 "가성비"로 규정되었고, 지금도 수출 단가가 낮다. 해안 서늘 산지와 노목 프로젝트가 그 프레임을 벗어나려는 시도다.
