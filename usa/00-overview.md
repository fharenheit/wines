# 미국 와인 개요

![미국 와인 산지 지도](../assets/usa-overview.svg)

## 1. AVA — 유럽 등급과 근본적으로 다르다

미국의 산지 제도는 **AVA (American Viticultural Area, 미국 포도재배지역)**이다. 1980년 도입.

| | 프랑스 AOC / 이탈리아 DOC | 미국 AVA |
|---|---|---|
| 규정하는 것 | 경계 + **품종 + 수확량 + 양조법 + 숙성** | **경계뿐** |
| 품종 제한 | 있음 | **없음** |
| 수확량 제한 | 있음 | **없음** |
| 양조법 제한 | 있음 | **없음** |
| 등급 서열 | 있음 (그랑크뤼 > 빌라주 등) | **없음** — AVA 간 상하 관계 없음 |
| 신설 주체 | 정부 심사 | **생산자 청원** → TTB 승인 |

> 핵심: **AVA는 "여기가 어디인가"만 말하고 "어떻게 만들라"는 말하지 않는다.** 나파 밸리 AVA에서 카베르네를 심든 진판델을 심든 자유다. 따라서 품질 보증 장치가 아니라 **지리 표시**에 가깝다.

### AVA 중첩 구조

AVA는 러시아 인형처럼 겹친다. 예:

```
North Coast AVA
 └ Napa Valley AVA
    └ Oakville AVA
```

라벨에는 이 중 어느 것이든 표기할 수 있고, 보통 **가장 좁은 AVA**를 쓸수록 값이 비싸다.

- 전국 AVA 약 **270개 이상**, 그중 캘리포니아가 약 150개
- 최초 AVA: **Augusta (미주리, 1980)** / 캘리포니아 최초: **Napa Valley (1981)**

## 2. 품종 색인 — 어느 문서에서 다루는가

미국은 AVA가 품종을 규정하지 않으므로, **어디에 무엇을 심는지는 기후와 시장이 정한다.** 각 지역 문서의 「품종」 절에서 그 논리를 다룬다.

| 품종 | 중심 산지 | 왜 거기인가 | 문서 |
|---|---|---|---|
| **Cabernet Sauvignon** 카베르네 소비뇽 | **나파 밸리** · 레드 마운틴(WA) | 여름 무강우 + 큰 일교차 → 매년 완숙 | [나파](01-napa.md) · [워싱턴](05-washington.md) |
| **Pinot Noir** 피노 누아 | **러시안 리버 · 소노마 코스트 · 윌라멧 밸리** | 태평양 안개·페탈루마 갭 / 위도 45°N | [소노마](02-sonoma.md) · [오리건](04-oregon.md) |
| **Chardonnay** 샤르도네 | 카네로스 · 러시안 리버 · 산타바버라 | 만·해안의 냉기로 산도 유지 | [소노마](02-sonoma.md) · [캘리포니아 기타](03-california-other.md) |
| **Zinfandel** 진판델 | **드라이 크리크 · 로다이 · 시에라 풋힐** | 금주법 이전 자근 노목이 남았다 | [소노마](02-sonoma.md) · [캘리포니아 기타](03-california-other.md) |
| **Syrah** 시라 | **왈라왈라 · 더 록스** · 산타바버라 | 현무암 자갈 / 서늘한 해안 | [워싱턴](05-washington.md) · [캘리포니아 기타](03-california-other.md) |
| **Merlot** 메를로 | 워싱턴 · 나파 | 워싱턴은 산도가 남아 진지해진다 | [워싱턴](05-washington.md) |
| **Riesling** 리슬링 | **핑거레이크스** · 워싱턴 | 호수 효과 / 서늘한 밤 | [그 외 주](06-other-states.md) · [워싱턴](05-washington.md) |
| **Pinot Gris** 피노 그리 | **오리건** | 1966년 미국 최초 식재 | [오리건](04-oregon.md) |
| **Sauvignon Blanc** 소비뇽 블랑 | 나파 · 드라이 크리크 | 몬다비의 **Fumé Blanc** | [나파](01-napa.md) |
| **론 품종** (그르나슈·무르베드르·비오니에·루산) | **파소 로블스** | 석회암 + 일교차 25℃. 론 레인저 운동 | [캘리포니아 기타](03-california-other.md) |
| **Cabernet Franc** 카베르네 프랑 | **버지니아 · 핑거레이크스** | 일찍 익어 가을 비를 피한다 | [그 외 주](06-other-states.md) |
| **Petit Manseng** 프티 망상 | 버지니아 | 껍질이 두껍고 송이가 성글어 습기에 강하다 | [그 외 주](06-other-states.md) |
| **Tempranillo** 템프라니요 | **텍사스** | 더위에 강한 이베리아 품종 전략 | [그 외 주](06-other-states.md) |
| **하이브리드** (비달·샹부르생·마르케트) | 동부·중서부 | 겨울 혹한과 곰팡이병을 견딘다 | [그 외 주](06-other-states.md) |

## 3. 라벨 규정 (연방 기준)

| 항목 | 최소 비율 |
|---|---|
| **품종 표기** | **75%** (오리건은 대부분 **90%**, 카베르네 소비뇽 등 일부는 75%) |
| **AVA 표기** | **85%** |
| 카운티 표기 | 75% |
| 주(州) 표기 | 75% — 단 **캘리포니아는 주법으로 100%** |
| **빈티지 표기** | AVA 표기 시 **95%** / 주·카운티 표기 시 85% |
| **Estate Bottled** | 100% 자가 소유 밭 + 와이너리가 같은 AVA 안에 있을 것 |

> **Reserve, Old Vine, Vineyard Select** 등은 **법적 정의가 없다.** 마케팅 용어일 뿐이며 생산자마다 기준이 다르다.

## 4. 역사 — 세 번의 단절과 도약

| 시기 | 사건 |
|---|---|
| 1769~ | 스페인 선교사가 **미션(Mission) 품종** 전파 |
| 1857 | 아고스톤 하라스티, 소노마에 **부에나 비스타** 설립 — "캘리포니아 포도재배의 아버지" |
| 1880년대 | **필록세라**로 괴멸 |
| **1920~1933** | **금주법(Prohibition)** — 산업이 사실상 소멸. 성찬용 와인과 가정 양조용 포도 출하로만 연명 |
| 1933~1960s | 저가 벌크 와인(저그 와인) 시대 |
| 1966 | **로버트 몬다비 와이너리** 설립 — 금주법 이후 최초의 대형 신설 와이너리 |
| **1976** | **파리의 심판(Judgment of Paris)** |
| 1980 | **AVA 제도** 도입 |
| 1990년대 | AXR-1 대목 실패로 **2차 필록세라** → 나파 대대적 재식재 |
| 1991 | CBS 「60 Minutes」의 **프렌치 패러독스** 방영 → 레드 와인 붐 |
| 1990~2000s | **컬트 와인** 시대. 로버트 파커의 영향으로 농익고 진한 고알코올 스타일 유행 |
| 2010s~ | **In Pursuit of Balance** 운동 — 저알코올·고산도로 반동 |
| 2017 · 2020 | 대형 산불과 **연기 오염(smoke taint)** — 기후위기가 현실 문제로 |

### 파리의 심판 (1976)

영국인 스티븐 스퍼리어가 파리에서 연 블라인드 시음회. 프랑스 심사위원단이 **캘리포니아 와인을 1위로 뽑았다.**

| 부문 | 1위 |
|---|---|
| 화이트 (샤르도네) | **Chateau Montelena 1973** (나파) |
| 레드 (카베르네) | **Stag's Leap Wine Cellars S.L.V. 1973** (나파) |

> 이 사건이 "신대륙 와인도 최고급이 될 수 있다"는 인식을 만들었고, 미국뿐 아니라 호주·칠레·뉴질랜드의 고급화에도 불을 붙였다.

## 5. 생산 규모

| 주 | 비중 | 성격 |
|---|---|---|
| **캘리포니아** | 약 **81%** | 절대적. 벌크부터 최고급까지 전 스펙트럼 |
| **워싱턴** | 약 5% | 고급 레드 중심, 가성비 |
| **뉴욕** | 약 4% | 리슬링(핑거레이크스), 보르도 품종(롱아일랜드) |
| **오리건** | 약 2% | 피노 누아 특화, 소규모 고품질 |
| 그 외 | 나머지 | 버지니아·텍사스·미시간·아이다호 등 **50개 주 전부에서 생산** |

## 6. 기후의 핵심 — 태평양 안개

캘리포니아 해안 산지의 스타일을 결정하는 것은 위도가 아니라 **안개와 바람이 어디까지 들어오는가**다.

| 요소 | 작용 |
|---|---|
| 캘리포니아 한류(차가운 해류) | 해안에 짙은 안개를 만든다 |
| 내륙 센트럴 밸리의 열기 | 상승 기류가 안개를 육지로 빨아들인다 |
| **산맥의 틈(gap)** | 안개가 들어오는 통로 — 페탈루마 갭, 샌파블로 만, 살리나스 밸리 |

> 그래서 **안개 통로에 가까울수록 서늘하고**(피노 누아·샤르도네), **멀거나 안개 위 산지일수록 덥다**(카베르네 소비뇽). 나파 밸리가 남쪽 카네로스에서 북쪽 칼리스토가로 갈수록 더워지는 이유다.

## 8. 유럽과 비교한 미국 와인의 특징

| 항목 | 내용 |
|---|---|
| **생산자 브랜드 중심** | 밭보다 와이너리 이름이 우선. 보르도와 유사한 구조 |
| **단일 밭 표기 증가** | 최근 To Kalon, Bien Nacido, Ciel du Cheval처럼 **밭 이름을 파는** 문화가 자리잡음 |
| **재배자-와이너리 분리** | 유명 밭(Beckstoffer, Sagemoor 등)의 포도를 여러 와이너리가 사서 각자 병입 |
| **컨설턴트 문화** | 미셸 롤랑, 헬렌 털리, 필립 멜카 등 스타 양조 컨설턴트의 영향력이 크다 |
| **오크 사용** | 신 프렌치 오크 비율이 유럽보다 높은 편 (최근 감소 추세) |
| **알코올 도수** | 14.5~15.5%가 흔하다. 유럽보다 1~1.5도 높음 |
