# 워싱턴 Washington

> 캐스케이드 산맥 **동쪽의 사막**. 오리건과 주는 붙어 있지만 기후와 스타일은 정반대다. 미국 2위 생산 주.

![태평양 북서부 지도](../assets/pacific-northwest.svg)

## 1. 기본 구조 — 사막에서 만드는 와인

| 항목 | 내용 |
|---|---|
| 위도 | **북위 46도** — 보르도·부르고뉴와 같은 위도 |
| 강수 | **연 150~200 mm**(사막 수준). 관개가 필수 |
| 일조 | 여름에 보르도보다 **하루 2시간 더 길다**(고위도 효과) |
| 일교차 | 크다 → 잘 익으면서도 **산도가 유지된다** |
| 주품종 | 카베르네 소비뇽, 메를로, 시라, 샤르도네, 리슬링 |
| AVA | 20개 이상 (대부분 Columbia Valley 안에 중첩) |

### 워싱턴만의 두 가지 특이점

| 특징 | 내용 |
|---|---|
| **자근(自根) 포도나무** | 모래 토양과 건조 기후 때문에 **필록세라가 정착하지 못했다.** 대부분 접목 없이 자근으로 재배 — 세계적으로 드문 조건 |
| **미줄라 홍수 토양** | 빙하기말(1만 5천 년 전) 대홍수가 실어온 자갈·모래·뢰스가 쌓인 지질. 배수가 극도로 좋다 |

> 반면 **겨울 동해(凍害)**가 최대 위험이다. 몇 년에 한 번 영하 20도 이하로 떨어져 나무가 죽는다. 자근이라 재식재는 비교적 쉽지만 수확량 변동이 크다.

## 2. 품종

> 워싱턴은 **품종 폭이 미국에서 가장 넓은 축**이다. 캐스케이드 산맥 동쪽의 사막 기후라 원하는 품종을 심고 **관개로 물을 조절**하면 되기 때문이다. 나파처럼 한 품종에 집중하지 않았다.

| 품종 | 재배 비중 | 비고 |
|---|---|---|
| **Cabernet Sauvignon** 카베르네 소비뇽 | 약 25% | 최대 재배 품종 |
| **Chardonnay** 샤르도네 | 약 15% | |
| **Riesling** 리슬링 | 약 12% | **한때 미국 최대 리슬링 산지** |
| **Merlot** 메를로 | 약 12% | 워싱턴을 알린 품종 |
| **Syrah** 시라 | 약 10% | 가장 빠르게 평가가 오르는 품종 |
| **Cabernet Franc · Sauvignon Blanc · Pinot Gris · Malbec · Grenache** | 나머지 | |

---

### 사막이 만드는 조건

| 항목 | 내용 |
|---|---|
| 위도 | **46~47°N** — 보르도(45°N)보다 북쪽 |
| 일조 | 여름 **하루 17시간** — 캘리포니아보다 2시간 길다 |
| 강우 | **연 150~200 mm** — 사실상 사막. **관개 없이는 재배 불가** |
| 일교차 | **20℃ 이상** |
| 결과 | **당은 충분히 익으면서 산도가 남는다.** 색과 탄닌이 진한데 신선함이 있다 |

> **관개가 도구가 된다** — 비가 오지 않으니 물을 정확히 조절할 수 있다. 성숙기에 물을 끊어 알을 작게 만들고 껍질 비율을 높이는 **의도적 물 스트레스**가 표준 기법이다. 유럽에서는 관개가 금지되거나 제한되는 것과 정반대의 조건.

> **자근(own-rooted) 포도나무** — 모래 비율이 높아 **필록세라가 번지지 못했다.** 워싱턴 포도나무의 상당수가 접목하지 않은 자근이며, 이는 세계적으로 드문 경우다. 다만 **겨울 혹한(-20℃ 이하)**으로 나무가 죽는 사고가 주기적으로 일어난다(2004·2010·2024).

### Cabernet Sauvignon 카베르네 소비뇽

| 항목 | 내용 |
|---|---|
| 향 | 카시스·블랙베리, **허브·민트**, 흑연 |
| 구조 | 색 진함 · 탄닌 굵고 잘 익음 · **산도가 나파보다 확실히 높다** |
| 비유 | **나파와 보르도 사이.** 나파만큼 익었는데 보르도만큼 산도와 구조가 있다 |
| 최상 | **Red Mountain 레드 마운틴** — 워싱턴에서 가장 덥고 바람이 강하다. 탄닌이 굵고 응축도가 최고 |

### Syrah 시라 — 워싱턴의 진짜 강점

| 항목 | 내용 |
|---|---|
| 향 | **후추·제비꽃·올리브**, 육향(bacon fat)·훈연·철분 |
| 구조 | 색 진하고 산도가 좋다. 알코올 13.5~14.5% |
| 비유 | **북부 론(에르미타주·코트로티)에 가장 가까운 신세계 시라**라는 평가가 굳어졌다 |
| 최상 | **Walla Walla Valley 왈라왈라 밸리**, 특히 **The Rocks District 더 록스 디스트릭트** |

> **The Rocks District of Milton-Freewater** — 행정구역상 **오리건**에 있지만 **워싱턴 왈라왈라 밸리 AVA에 속한다.** 미국에서 유일하게 **단일 토양(현무암 강자갈)**만으로 경계가 정해진 AVA로, 여기 시라는 육향·철분·올리브 뉘앙스가 극단적으로 뚜렷하다. **Cayuse 카유스 · Reynvaan 레인반 · No Girls**가 대표.

### Merlot 메를로 · Riesling 리슬링

| 품종 | 내용 |
|---|---|
| **Merlot 메를로** | 1990년대 워싱턴을 알린 품종. 캘리포니아 메를로가 물러진 것과 달리 **워싱턴은 산도와 구조가 남아** 진지한 와인이 된다. **Leonetti 레오네티 · Andrew Will 앤드루 윌**이 대표 |
| **Riesling 리슬링** | 서늘한 밤 덕에 산도가 유지된다. **Chateau Ste. Michelle 샤토 생 미셸**이 독일 모젤의 **Dr. Loosen 닥터 로젠**과 합작해 만든 **Eroica 에로이카**가 상징 |

### 그 밖의 품종

| 품종 | 비고 |
|---|---|
| **Cabernet Franc 카베르네 프랑** | 서늘한 구획에서 루아르식으로 만드는 생산자가 늘고 있다 |
| **Grenache · Mourvèdre · Viognier · Roussanne** | 론 품종. 왈라왈라·야키마에서 |
| **Sangiovese · Tempranillo · Barbera** | 소수 실험 |
| **Sauvignon Blanc · Sémillon** | **Boushey · Klipsun** 등 오래된 밭. 세미용 노목은 워싱턴의 숨은 자산 |

### 밭이 브랜드가 되는 구조

워싱턴은 **재배자와 와이너리가 분리**된 경우가 많다. 그래서 나파의 벡스토퍼처럼 **밭 이름이 라벨에 오른다.**

| 밭 | AVA | 비고 |
|---|---|---|
| **Champoux 샹푸** | Horse Heaven Hills | 1972년 식재. Quilceda Creek 등에 공급 |
| **Ciel du Cheval 시엘 뒤 슈발** | Red Mountain | 여러 와이너리가 나눠 산다 |
| **Klipsun 클립순** | Red Mountain | |
| **Boushey 부시** | Yakima Valley | 시라·론 품종 |
| **Sagemoor 세이지무어** | Columbia Valley | 1968년 식재, 주 최고령 밭 중 하나 |

### AVA 구조 — 중첩이 심하다

```
Columbia Valley AVA (컬럼비아 밸리, 주 전체의 99%)
 ├ Yakima Valley (야키마 밸리)
 │   ├ Red Mountain (레드 마운틴)
 │   ├ Snipes Mountain
 │   └ Rattlesnake Hills
 ├ Walla Walla Valley (왈라왈라 밸리)
 │   └ The Rocks District (오리건 쪽)
 ├ Horse Heaven Hills
 ├ Wahluke Slope
 └ Royal Slope · Candy Mountain 등
```

> 라벨에 **Columbia Valley**만 적혀 있으면 주 전역 어디서든 올 수 있다는 뜻이다. 하위 AVA가 좁을수록 밭이 특정된다.

## 3. AVA 구조

**Columbia Valley AVA (1984)**가 우산처럼 덮고 그 안에 하위 AVA가 들어 있다. **워싱턴 생산의 약 99%**가 이 안에서 나온다.

```
Columbia Valley AVA
 ├ Yakima Valley ─┬ Red Mountain
 │                ├ Snipes Mountain
 │                ├ Rattlesnake Hills
 │                └ Candy Mountain
 ├ Walla Walla Valley ─ The Rocks District (오리건 쪽)
 ├ Horse Heaven Hills
 ├ Wahluke Slope
 ├ Ancient Lakes / Royal Slope / Lake Chelan / White Bluffs …
```

### 주요 하위 AVA

| AVA | 지정 | 성격 | 대표 밭 · 생산자 |
|---|---|---|---|
| **Yakima Valley** | 1983 | **워싱턴 최초의 AVA**. 서늘한 편, 다양한 품종 | **Boushey Vineyard**, Dubrul / Owen Roe, Côte Bonneville |
| **Red Mountain** | 2001 | **워싱턴 최고가 카베르네.** 면적이 작고 매우 덥고 바람이 강해 껍질이 두껍다 → 탄닌이 굵다 | **Ciel du Cheval**, **Klipsun**, **Kiona** 밭 / **Quilceda Creek**, Col Solare(안티노리 합작), Cadence, Force Majeure |
| **Walla Walla Valley** | 1984 | 오리건과 공유. 워싱턴 고급 와인의 문화적 중심 | **Leonetti Cellar**, **Woodward Canyon**, **L'Ecole No 41**, Figgins, Gramercy Cellars |
| **The Rocks District of Milton-Freewater** | 2015 | 왈라왈라 안, **행정구역은 오리건**. 현무암 자갈 하상 → 훈연·올리브 향의 시라 | **Cayuse**, **No Girls**, **Reynvaan**, Delmas |
| **Horse Heaven Hills** | 2005 | 컬럼비아 강변, 바람이 강함 | **Champoux Vineyard**(퀼세다 크릭의 핵심 밭), Andrew Will |
| **Wahluke Slope** | 2006 | 가장 덥고 건조. 남향 완사면 | Milbrandt |
| **Ancient Lakes of Columbia Valley** | 2012 | 서늘. **리슬링·샤르도네 등 화이트** | Evergreen Vineyard |
| **Lake Chelan** | 2009 | 호수의 완충 효과 | |
| **Royal Slope** | 2020 | 고도 높음 | |
| **Puget Sound** | 1995 | **캐스케이드 서쪽의 유일한 AVA**. 서늘·습윤, 독일계 품종 | |

## 4. 핵심 생산자

| 생산자 | 비고 |
|---|---|
| **Quilceda Creek** | 워싱턴 카베르네의 정점. 파커 100점을 여러 번 받으며 워싱턴을 알렸다 |
| **Leonetti Cellar** | 왈라왈라 1호 와이너리(1977). 회원제 |
| **Woodward Canyon** | 왈라왈라 2호. 클래식한 스타일 |
| **Andrew Will** | 밭별 보르도 블렌드(Sorella, Champoux) |
| **Cayuse Vineyards** | 크리스토프 배런(샹파뉴 출신). The Rocks District 개척, 비오디나미. 회원제 대기자 명단 |
| **DeLille Cellars** | 보르도 블렌드 전문 |
| **Betz Family Winery** | 밥 벳츠 MW |
| **Gramercy Cellars** | 그레그 해링턴 MS. 시라·구세계 지향 |
| **Cadence · Force Majeure · Owen Roe · Long Shadows** | |
| **Château Ste. Michelle** | 워싱턴 최대. **Eroica**(독일 Dr. Loosen과 리슬링 합작), **Col Solare**(안티노리와 카베르네 합작) |
| **K Vintners / Charles Smith** | 시라 중심, 파격적 라벨 |

> 워싱턴은 **재배자와 와이너리가 분리된 구조**가 뚜렷하다. Sagemoor, Champoux, Ciel du Cheval, Boushey, Klipsun 같은 유명 밭의 포도를 여러 와이너리가 사서 각자 병입한다 — 밭 이름이 곧 품질 지표다.

## 5. 워싱턴 vs 나파

| | 나파 | 워싱턴 |
|---|---|---|
| 기후 | 지중해성, 안개 | **사막**, 관개 필수 |
| 위도 | 38도 | **46도** — 일조시간이 더 길다 |
| 대목 | 접목 (필록세라) | **자근** |
| 카베르네 스타일 | 농익은 과실, 부드러운 탄닌 | **산도가 살아 있고 탄닌이 각진다.** 보르도에 더 가깝다는 평 |
| 최대 위험 | 산불·연기 오염 | **겨울 동해** |
| 가격 | 높음 | **같은 품질 대비 절반 이하** — 미국 최고의 가성비 산지 |

---

## 6. 실전 요령

- **"Columbia Valley"만 적힌 와인**은 광역이다. Red Mountain·Walla Walla 표기가 있으면 훨씬 좁은 곳.
- 워싱턴 카베르네·메를로는 **나파보다 산도가 높고 값이 싸다.** 구세계 스타일을 선호하면 워싱턴이 잘 맞는다.
- 시라를 찾는다면 **The Rocks District** — 미국에서 가장 독특한 시라가 나온다.
- 리슬링은 **Ancient Lakes**와 Eroica.
